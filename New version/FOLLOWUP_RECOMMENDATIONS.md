# 后续修改和研究建议

日期：2026-10-14

当前模型结果已经确定了下一步重点：先建立真实数据的公式级真值和数据隔离，再修改模型的候选选择层。旧模型代码保持可回归状态。

## 1. 研究主问题

建议把主题收窄为：**在合法业务例外、跨表角色差异和相关复制错误存在时，模型能否减少错误修改建议，同时保留可接受的正确修复覆盖率。**

这个问题直接对应当前证据：V4 在开发集有 3,408 个正确公式格错误候选，V5.1.1 仍有 27 个；两个后端接受覆盖相同。Enron 回归又显示，候选少不等于独立真实数据上的定位更好。

旧研究计划记录原论文版本在合法异构、共享错误和组内例外上的失败。本轮没有重新运行论文 0.3.0，旧计划中的失败数字属于旧报告记录。当前应以 [本轮模型结果](CURRENT_MODEL_RESULT.md) 为新的基线说明；`research/hybridguard_followup_20261014/PLAN.md` 中“本次未重跑”描述的是本轮运行之前的阶段。

可以预先登记两个可证伪问题：角色和例外门控能否在相近覆盖下减少错误建议；独立批准约束或来源关系能否改善相关复制错误中的候选选择。如果收益完全来自拒绝全部建议，或简单规则同样有效，应缩小方法和结论。

## 2. 修改顺序

### 阶段 A：先完成数据适配，不改旧模型

- 固定当前 V4、V5.1.1 的源码、环境、配置和预测锁。
- 完成 EUSES、Integer、Info1 的原表配对和公式保真检查。
- 把每个单元格标为 `error`、`correct`、`legitimate_exception` 或 `unknown`；没有足够证据的单元格保留 `unknown`。
- 以模板家族和近重复簇划分开发、留出和控制集。同一模板的月份、地区、复制版本和注入版本不能跨集合。
- 先锁一小批新数据的当前模型预测，再接触标签评分。

阶段 A 的完成条件是：每个主实验样本都有来源、家族、工作簿哈希、公式真值状态和转换记录。没有达到这个条件时，不开始用新数据调阈值。

### 阶段 B：增加候选安全门控

保留现有候选生成器，新增选择层，便于判断错误来自候选生成还是候选选择：

1. 检查表头、汇总/明细位置、函数类型、引用方向和依赖邻域是否属于同一角色。
2. 识别跨表复制关系。多个表使用同一错误模板时，不能把多数票当作独立证据。
3. 记录已声明的区域边界和合法例外。发现组内例外时，初版拒绝整组修改。
4. 为每条输出加入 `propose`、`review`、`abstain` 或 `unsupported` 状态、候选公式、证据和拒绝原因。
5. 联合约束修复只使用检测前外部批准的业务约束；保留“不修改”选项。无约束结构候选属于独立模式，不把错误标签、正确公式或人工答案转成约束输入。

Enron 的 8 个旧逻辑接受决策来自无约束结构策略，正确性未知。新选择层应对这一路输出也作审查，不能因为搜索状态是 `no_approved_constraints` 就假定系统已经拒绝全部建议。

建议先实现简单的角色规则，再决定是否需要学习模型。若简单规则与复杂版本效果相近，论文应采用简单版本并报告适用范围。

### 阶段 C：做可解释的对照和消融

至少保留以下对照：

- 原论文 HybridGuard 0.3.0 或其可复现基线；
- 当前 V4；
- 当前 V5.1.1；
- 当前候选加简单角色规则；
- 完整门控；
- 去掉角色检查、去掉例外检查、去掉来源关系检查的消融；
- `reject_all` 零覆盖对照。

所有方法使用相同输入、相同标签隔离和相同检查预算。V5.1.9 的批准约束实验另列，不和无约束方法合并总分。

## 3. 必须同时报告的指标

- 正确公式格上的错误候选数和比例；
- 全部候选建议精确率；
- 最终接受建议精确率；
- 正确修复覆盖率，拒绝的错误仍进入分母；
- 不安全组率；
- Top1、Top5、Top10 定位召回；
- 风险-覆盖曲线、拒绝比例、未知标签比例、每工作簿耗时和内存；
- 工作簿数、模板家族数和近重复簇数。

没有接受建议时，接受精确率记为不适用，覆盖率记为零。公式文本相同只能算精确匹配，数值相等不能单独证明业务等价。

建议预先写下开发门槛：保持当前开发集的正确接受覆盖率下降不超过 5 个百分点、接受不安全组仍为零，同时使 V5.1.1 的正确格错误候选从 27 个减少至少 80%，即最多 5 个。这是下一轮可调整但需在实验前登记的开发目标，尚未达成。V4 的 3,408 个错误候选另列，不借用它的大分母宣称新方法胜出。外部基线完成后再固定外部数据的可行门槛，留出集冻结后不修改。

风险与覆盖比较必须针对同一层输出：候选层比较候选建议精确率与正确候选覆盖，最终接受层比较接受精确率与正确接受覆盖。当前主模式零观测误接受不足以证明门控可以提高真实安全性。

误差分析和不确定性估计以工作簿或模板簇为单位，不把同表的数千公式视为独立样本。Info1 只有两个模板时，以逐模板结果为主，不能支撑广泛业务泛化结论。

## 4. Enron 的处理方式

Enron 继续作为定位回归集，不能作为修复精确率主实验。下一轮应延长超时只作为独立补充实验，不能覆盖本轮 180 秒边界结果。当前 8 个 `stable_copy_template` 接受决策的正确性未知，应单独显示为“待人工核查”，不计入修复正确数。

## 5. 推荐执行顺序

1. 完成数据适配和小样本人工试标。
2. 用未修改的 V4、V5.1.1 先跑外部 baseline。
3. 冻结数据版本、家族划分、方法清单和评分程序。
4. 实现候选安全门控和四状态输出。
5. 在开发家族上调规则，在留出家族上锁预测后评分。
6. 汇总风险、覆盖和失败案例，再决定论文实验范围。

这一步完成后，才有依据决定 V4、V5.1.1 或新门控版本作为论文主方法。
