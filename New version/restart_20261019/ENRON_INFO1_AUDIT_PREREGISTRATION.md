# Enron / Info1 来源补审登记

本登记先于本轮原作者包内更正公式的读取及 Info1 全表内容审计。已阅读旧定位标签、原作者公开事件映射和 Info1 论文第6.2节，因此整个 Enron / Info1 来源均为开发证据，最终留出资格为 false。不修改冻结模型。

## 问题与证据

Enron 旧包是 TU Graz 的定位适配版，不包含所有更正工作簿。原作者页面另有完整 ZIP，公开36事件的错误/更正文件、工作表和位置映射。本轮核查完整包CRC、每个原件与旧定位包的字节哈希，以及原/更正逐格内容。文件名中的1/2及ZIP时间戳不能代替事件映射或邮件时间线。

Info1 官网有两种练习；2015年论文6.2节明确学生从零创建、没有结构模板，且多个测试输入来自同一学生作品。因此两种练习不是已确认的两个模板家族。按课程、学生身份先分组，再记录布局/公式近重复；不得把119个文件当119个独立来源，也不得按FAULTVERSION切分。包中缺少样例解与正确公式，其他学生的多数公式及expected output不能直接作为修复真值。

## 执行与指标

1. 保存URL、HTTP状态、哈希、获取时间及原始文档；第三方文件仅存忽略目录，不再分发。
2. LibreOffice以ReadOnly、MacroExecutionMode=NEVER_EXECUTE、UpdateDocMode=NO_UPDATE加载每个文件，独立进程与用户配置，读取原生公式和单元格类型；只向隔离副本导出xlsx，再重开核对所有单元格公式/值。记录差异，转换不保真者不进入模型。
3. 每本一个任务，8进程。对同一固定小批次另跑1进程，报告墙钟、CPU、采样并发RSS、吞吐和加速比，并核对库存内容哈希；此测量仅说明本批来源审计，不代替模型推理性能。
4. 所有36事件保留，区分：无更正版、无公式修正、结构/输入变化、引用角色映射未确认、公式修正候选。逐格修复真值还须邮件/作者解释与工作簿业务证据；相同位置改式不是自动判真。
5. Info1按每个FAULTY_CELLS标签记录公式/常量/空格/缺失表，重复学生与相同内容另报。仅能支持错误位置指标时明确写出；正确输出格不是干净工作簿证明。

## 停止规则

无法恢复输入不变的正确原角色公式、原生/转换差异未解释、或缺少独立语义依据时，不计算该事件修复准确率。已知错误保留在完整分母台账，不能只挑容易配对事件报告双90%。本轮不调范围规则，不接入E2；若发现可用更正对，先形成逐事件证据，之后另登记模型诊断。
