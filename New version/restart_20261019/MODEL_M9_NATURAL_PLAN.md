# M9固定规则：自然开发与合法例外检查

沿用已锁定M9 SG已发出冲突优先规则与真实xlsx入口，不改阈值、候选、来源筛选或字段映射。前轮在两套已揭示注入/差异基准上的增益不足以证明自然性能，因此本轮必须检查自然错误和正确原式保持。

## 固定49本输入与分组

- 4份自然缺陷原件：cv-500（505个已认证错误）、EPA Flares（5）、Oxidizers（1）、AEDIST原件（2），合计513错误。AEDIST为既有只读转换xlsx副本，不扩展宣称原生ODS支持。来源全部已揭示，永久排除最终留出。
- 2份修订后控制：cv-500全部505个已核原公式、AEDIST仅2个已核修订目标。其余AEDIST公式仍未知，不能把整表当干净真值。
- 1份Software Metrics原件：28个范围缺陷候选/160个空白边界控制；不与513已认证自然错误合并计分。固定原输入时仅8个候选有已核输出差异，其余数值巧合不能算正确修复。
- 完整16份dev29记录文本控制（8错误/8合法或信息不足），保留同可见内容不同外部意图的四对；不把人工反例当自然分布。
- 完整26份dev32已登记的新财务控制，含正确、错误、合法调整、冲突说明、隐藏/不支持等全部场景；仅作者登记的目标格有真值，上游其余公式未知。

不增加复制任务来占满20核，不根据当前M9结果抽样。所有真值/修订件/原预测只由准备与评分进程读取；推理49任务只读取各自源工作簿。元数据包含当前历史暴露状态，不伪称盲测。所有输入、代码、评分键及历史基线哈希在推理前锁定，49终态/输出锁定后独立评分。固定20 workers，无性能比较。

## 核验与决策

自然4原件与有完整历史paper的其他自然表逐字段核对原paper重现；dev32历史只保存修改建议列表，故只核对建议映射，不声称其完整行字节复现。dev29控制此前是候选生成实验，没有完整paper预测，本轮直接保留paper与M9成对输出。

独立评分不导入融合实现，逐行核对唯一允许的FG/SG选择变更；分别报告各组全部修改建议、已知错误全文本精确恢复、已知正确目标被修改、建议落在未知区、得失与终态。513分母保留未知/失败/超时；范围候选不混入。自然全表真值不全时不报告完整业务精确率，只给相对于已认证错误的精确匹配占比并明确未知数；cv-500全公式已标注可以单独计算。

正确目标上的新公式不等于登记式，只先记为“正确原式被修改/精确合同保持失败”，不能在未验证语义前全部称业务误改；若出现新保持失败，须进一步独立执行/等价审查。所有未知建议仍留在分母。

自然接入的必要门槛：49项完整、可复核的历史对照一致；自然正确修复数严格增加且原有正确不丢失；各组正确原式被修改数均不增加；全部建议不增加。任一未满足则M9不具自然接入资格，保持默认原论文模型，不按旧案例改优先级；已有注入基准增益只保留为消融结论。通过也不是最终6来源/15家族及双90%达成。
