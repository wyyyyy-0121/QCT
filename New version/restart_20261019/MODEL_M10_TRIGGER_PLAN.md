# M10：无触发门的原候选器可达性消融

自然追踪发现513个已认证错误均未调用FG候选器。先检验必要条件：不改变候选器、半径5、同伴支持2、上限24或业务输入，对每个原公式调用原候选器，是否会增加正确式可达性。原来已经调用的探测结果原样复用，只补此前没有调用的格；SG实际池不变。此阶段不改变排序、分数、发出门或最终建议，不能报告模型准确率提升。

输入为M9已固定的完整49本：4本自然原件513错误、2本修订控制507正确目标、1本Metrics28候选/160空白控制、16本记录文本控制和26本财务控制。42个人工控制中的192错误、156正确目标分组保留。来源全部揭示，永久排除最终盲测。不复制任务、不排除难例，失败/超时保留在各组分母。批量固定请求20 workers，不做性能档位实验。

先在每个工作簿真实运行冻结原论文并追踪实际调用，再补原候选器未调用格。推理只读该工作簿，不读修订件、历史预测、评分键或业务说明。准备锁定源表、已有M9输入/输出、评分键、代码、计划；全部49终态和追踪输出锁后独立评分，与M9的original_paper及公式库存逐字段比较。

独立评分分别报告原池/补齐池精确式可达数、新增/丢失、FG调用数、未知区候选数量及已知正确格上产生修改候选的数量。后两者是候选风险/库存，不能当作模型建议或已证误改。全文本匹配不排除未认证的业务等价式；Metrics候选不能并入513自然错误。

只有49项完整、原论文逐字段复现、原池不丢失且自然精确候选严格增加，才继续评估“仅移除触发条件、其他原评分/发出/融合不变”的实际模型。若自然候选仍0，则停止移除触发门路线，不再放大候选上限、改半径/阈值或混入M3/M5/dev29候选器。即使可达性增加，也必须后续独立检查全部建议精确率、覆盖和合法例外，不能凭候选可达宣称90%。
