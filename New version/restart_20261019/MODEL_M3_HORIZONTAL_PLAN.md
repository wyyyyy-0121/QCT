# M3：横向同伴候选生成，单因素实验

登记在M2追踪结论之后、M3预测之前。全部SpreadsheetBench 2数据已揭示，仅作开发。本轮直接扩展论文候选生成能力，不改原冻结源码、不引入旧QCT模型、不调整分数或选择门槛。

## 固定生成机制

输入仅为90项冻结paper预测中的原公式库存。同一表同行，左右各半径5列的原公式用论文FormulaGuard原生解析/平移器复制到目标。完全相同候选获至少两个同伴支持时，且与原式不同，加入独立候选池；保留支持计数和源格。只对已有公式目标运行，不暗中填补常量/空白，扩展接口须另做实验。使用原半径5和支持2，不搜索参数。

候选生成不自动采纳，不将候选可达率当作修复准确率。合法业务例外中即使生成了候选也不得直接改公式。目标原式与候选均须被原解析器接受，拒绝直接/范围自引用及原模型未支持的表达式。命名范围/结构化引用仍视为不支持。

## 运行与判断

固定20 workers，沿用90项已完成输入；10项原超时仍保留在10,948个普通候选分母。推理不读取候选差异、golden或任务说明。锁定全部候选后，独立诊断器读取既有M2追踪和差异，比较原观测池与新增横向池的精确目标可达性。

继续研究此生成机制的必要条件：相对原池至少新增100个精确目标，且每个新增精确目标的新增不同候选数不超过100；两个条件都通过才可研究选择层，未通过则停止此机制，不在当前数据搜索窗口/支持数。无论是否通过，报告新增候选总量、候选可达率、全分母覆盖及未知/超时，不宣称90%修复目标达成。即使可达率提高，也须后续独立验证选择精确率和业务正确性。

测试涵盖横向翻译、固定绝对/跨表引用、低支持拒绝、直接/范围自引用、原式不变和合法业务例外。新候选只存忽略目录；GitHub保存实现和聚合结果。
