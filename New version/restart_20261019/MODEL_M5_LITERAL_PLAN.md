# M5：保护字面量的单因素模型修正

在M4确认具体变换缺陷后、M5模型运行前固定本方案。原论文包及原预测不改；在独立预测进程中暂时替换三个FormulaGuard变换函数：复制平移、小改动候选生成、规范化。双引号字符串与单引号表名先以唯一占位标识保护，原函数处理其余语法，再逐字恢复原内容。没有引号的公式必须与原函数输出完全一致。

仅此一项改动，不实现新的解析语法或函数、不改候选半径/上限/门槛/融合；StructuralGuard平移器原本已有字符串保护，不替换。修正不代表能够理解字符串或识别业务错误，非法引用/未支持语法继续保持原状态。

## 验证

1. 机制测试必须证明：引用文本、转义引号、运算符文本、字符串大小写和空格完整保留；表名字符不被候选变换破坏；实际引用仍按原规则移动；不含引号的公式输出与原版一致；上下文退出后原函数恢复。
2. 独立构造工作簿用Calc只读强制重算，至少覆盖原平移器破坏的字符串返回值、未激活分支中的字符串以及混合绝对引用。检查器不能读取模型结果生成期望值；预期输出先单独登记锁定。
3. 90项原基线成功任务用20 workers运行仅paper的新预测，10项超时继承且不补成功。预测进程不得读取golden、标签或旧差异。实现、输入和输出全部锁定后独立计算全部建议数、精确候选、候选精确率/覆盖，不作新增盲测声明。

若保护变换改变无引号公式行为、独立Calc语义不符，或新增预测的候选精确率/覆盖任一低于原普通公式诊断基线，则停止主模型采纳，保留工程修正和失败证据，不在本数据调阈值。通过上述门槛仅允许继续研究，不能宣称自然准确率或90%达标。
