# M9第二基准评分更正：剔除与原式相同的无改动建议

在M9第二基准225份推理结果全部锁定之后，首次`tools/score_external_m9.py`独立复算触发`Historical scoring mismatch`，未写出正式指标文件。原评分器及实验输入/输出锁保持原状。

核查旧`FAULTSFW_RESULTS_20261019.md`的2116条是全部以等号开始的建议行，其中94条建议公式与输入原式相同，不是修改建议。按当前研究一直使用的“与原式不同的全部建议”口径，原基线分母应为**2022**；已认证374故障格、149正确修复均不变。旧报告保留，不覆盖历史证据。

本次更正同时应用于paper和M9，不更改模型、样本、标签或预测；225个xlsx、6个真值未知版本及27个xls支持限制保持不变。M9初版评分器不改；新增`score_external_m9_v2.py`，只补充更正锁与改正历史总量核对/精确率比较阈值，仍用原独立exact_metrics，保留首次中止及逐行分母审计。新评分器与本文、原输入/输出锁、分母审计先生成单独的`scoring_amendment_lock.json`再运行。

此更正发生在输出锁定后、独立评分已打开标签之时，不能声称v2评分器在推理前锁定。因不涉及任何推理或规则变化，不重跑推理来假装事前登记。采用正确分母后的对照门槛为：原精确修复保留95%、全部修改建议不增、正确数至少149、精确率不低于149/2022；较旧149/2116精确率门槛更严格。自然准确率/90%及来源隔离要求不变。
