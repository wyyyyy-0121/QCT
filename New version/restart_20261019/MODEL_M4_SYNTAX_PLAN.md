# M4：语法与执行能力库存

沿M2/M3的输入/解析主线，先做固定诊断，不改模型、不调阈值。20 workers读取90项冻结预测的原公式；每格调用原解析器，记录失败类型及多重语法特征。原10项超时不重跑，目标继续保留。合法字符串、逻辑字面量、百分号、错误引用、命名引用等分开记录，不将解析成功当作可执行或业务正确。

使用openpyxl词法器补充类型，但不以其接受公式为Excel语义认证。成功AST中不在原执行器支持集合IF/SUM/AVERAGE/MIN/MAX/COUNT内的函数单独计数；这只是执行器不支持函数的静态证据，不能代替实测。

诊断全部终态锁定后，再与既有普通公式候选差异连接，分别统计原式/目标式解析状态和已观测池无精确式目标。总体不支持比例不等于错误目标中的瓶颈。诊断证据决定下一单因素开发：优先处理能够完整实现解析、复制和执行语义的语法类别，不仅让解析“通过”。绝不将`#REF!`、命名范围或业务定义缺失默默转为数值。

原始公式和错误消息仅存忽略目录，公开聚合计数。原论文包与预测锁不改，不通过丢弃不支持样本提高指标。
