# M6–M8揭示的模型输入缺口

本表记录当前真实证据与缺项，不是新评分标签或人工认证合同。EPA全部已揭示，只作开发。明确算式能够提取，不等于字段能映射；地址能匹配，不等于业务关系适用；关系验证成立，也不等于工作簿所有建议正确。

| 缺口 | 当前证据 | 还需要什么 | 不应采取的补丁 |
| --- | --- | --- | --- |
| 同一符号的不同工况 | Qwi同时用于标准流量和实际流量，原表有完整描述 | 将关系中的工况与字段工况逐项对齐；动态单位若要使用，须验证表达式和适用分支 | 只按Qwi或邻近程度选地址；把缓存单位当普遍定义 |
| 来源名称与表头名称不一致 | M7两处算式的浓度短语没有对应的完整静态标签 | 从独立说明/表结构建立可定位的数据字典，区分总量、组分与稀释前后；记录定义来源 | 从目标公式引用反推同义词再称自动映射 |
| 同词但不同业务阶段 | LELmix的显式标签指向D31，而已给定的稀释后合同用S28 | 明确关系作用于原混合气还是稀释后混合气，验证组成变化及表区角色 | 把唯一词面匹配视为语义认证；只补另一个字段后直接放行 |
| D36关系本身并未由原文直接给出 | 手册说明需要稀释，表中定义因子/流量，M6手写关系可生成修复 | 逐项支撑因子定义、守恒组分、稀释介质、相同温压基准及适用分支，再建立可复核的推导；也可接受明确来源的专家合同，但须计入人工输入 | 把物理常识猜想/修订公式包装成来源明确算式 |
| 默认输入未激活错误分支 | EPA原值常落在不稀释或不适用分支，单点无法区别公式 | 使用有业务依据的域和多个可区分输入，正确记录适用/不适用分支；必要时独立重算 | 只比较当前缓存；用超物理范围数学控制宣称自然正确 |

## 下一步执行约束

1. 先在已有原件/官方说明中补齐可追溯的字段定义与关系适用性证据，保留原文定位与哈希。无法证明的行保持unknown，不由模型自行认证。
2. 只在证据足够时登记一个新的关系适用性实验：至少包含原错误、正确原式和不同工况/合法业务例外，明确哪些输入来自人工。原错误修复与误改同时考核；字段查询或拒绝组件通过不能替代端到端增益。
3. 若仍缺关键定义，停止继续扩写EPA专用解析/标签规则，转向原论文尚未排除的候选生成/融合缺口或新的有真值来源。不能用更多工程通过数掩盖自然验证未推进。
4. 最终全部建议精确率和正确修复覆盖仍分别要求至少90%，保留未知、拒绝、不支持、超时和失败；来源与模板隔离要求不变。后续批量固定20 workers，及时提交GitHub。
