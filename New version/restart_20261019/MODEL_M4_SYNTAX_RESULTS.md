# M4：语法库存与下一项代码修正

20-worker完成90/90项冻结成功任务的输入公式语法诊断，118,071个原公式中113,160个可解析、4,911个不支持。4,911个失败的主类为文本字面量3,302、百分号340、错误字面量421、命名/非单格引用848；主类互斥，多重特征另行保留。解析成功的公式中还有6,572格含原执行器不支持的函数（如CHOOSE、YEAR、INDEX/MATCH、IFERROR），不能称为可执行成功。

10,948个既有普通公式候选中，已完成任务5,555格里有427格原式不支持；2,475格“观测池无精确式”中2,077格原式和目标都可解析。因此不能将主要漏修归因为语法缺项。原超时5,393格仍完整保留。全部为已揭示、未认证业务真值的开发诊断。

原执行器不支持TABLE；现有目标中有1,000个可解析TABLE公式，可能涉及数据表特有语义而非普通公式编辑，必须保留未认证状态，不能按普通可执行公式宣称能力。原式与golden地址和结构对齐尚未独立认证。

本轮确认一项可直接复现的实现缺陷：原FormulaGuard平移器会把`=IF(A1=0,"A1+B1 / SUM",B1)`中的文本也从A1/B1改成A2/B2；原小改动生成器37个候选中23个改变了该字符串，原规范化还会将`"New York"`改为`"NEWYORK"`。字符串中的引用、运算符和词语不是公式语法，变换不应修改它们。

下一单因素修正是保护文本字面量（及被引号包围的表名）免受原公式变换影响，不顺便实现更多语法或函数，不改排序门槛。独立Calc检查复制后字符串输出及算术输出；随后在原100项分母上比较完整建议。工程完整性改进与修复性能提高分别报告，无增益则不宣称模型达标。

本批墙钟1.303秒、CPU合计19.90秒、采样聚合RSS约1017MiB，仅为静态语法扫描。公开汇总为`MODEL_M4_SYNTAX_SUMMARY.json`，逐格诊断仅保存在本地忽略目录。
