# dev13 行列参照一致性开发消融

目的：检验不依赖业务表头字典的局部参照候选能否减少漏修，同时记录误建议。只在此前已揭示的167个开发工作簿及11个已排除来源的公开工作簿记录上实验；不接触保留的最终来源。public05继续作为拒绝输入，不读取单元格。

方法在预测前固定：目标单元格周围每个轴最多检查正负1、2格；一个轴至少两个公式邻居，所有存在的公式邻居完整支持且平移后AST完全一致。候选与观测式只允许一个引用叶子的行或列发生变化，不改变运算符、常数、函数、工作表或绝对/相对标记。拒绝自引用，以及直接引用目标的支持邻居。默认要求两个轴指向同一个候选，另记录只用行或只用列的消融。

新候选与冻结dev11已有建议合并，仅在原来没有propose的格增加建议；不改变原dev11建议，不把语法或多数一致当业务真值。此策略可能误改未标记合法例外，因此只作为实验，默认不采用。两方向一致也不能证明参照独立。

167例使用已锁定dev12记录中的观测公式及dev11输出；公开记录使用已锁定静态视图或此前成功读取的原始开发输入。运行前哈希固定源码、计划、上游预测和原输入，运行时禁止读取标签/评分/作者oracle文件；完成预测锁后另进程评分。报告各历史组，不能合并掩盖退化。公开工作簿没有业务真值，只报告候选数量与范围，不报告精确率或覆盖率。

必须逐项重放新候选并复核评分。计时仅包含读取上游记录、必要的公开公式载入及新策略，不包含已冻结的原论文SG/FG/dev11运行成本。所有拒绝和失败保留。本轮最终合格来源/家族保持0，主目标active。
