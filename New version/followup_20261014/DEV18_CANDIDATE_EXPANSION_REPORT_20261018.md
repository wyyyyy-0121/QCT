# dev18：候选可达率提高，跨来源选择仍未达标

已完成五个保守来源组的213例开发交叉拟合。新三个公开开发来源的可用正确候选从dev17的13/78增至75/78；实际只修对Packt的4格，其他公开来源仍零修复。旧人工合成来源新增17正确、12错误建议。故不采用dev18为主模型，不宣布双90%完成。所有数据均已参与开发，最终合格来源/家族仍0；自然错误可靠配对仍未完成。

## 方法与隔离

保留论文原模型、dev11主候选及冻结旧记录。在既有无标签流程已提出不同公式假设的单元格，新增通用有界单编辑候选：运算替换、引用偏移一格、字面量比例删除和单目符号编辑。没有按答案定位目标，也没有从期望公式构造候选。没有初始候选的格子本轮不扩展，其错误仍计分母。新增候选最多256/格、512tokens，未发生截断。完整AST门和隐藏目标弃答保持。

旧101维特征扩到162维，增加引用类型、范围大小、相对距离、自引用和编辑来源指示。不读公式缓存值大小，不输入来源、路径、绝对坐标、家族、场景或答案。仅已认证局部关系生成训练标签；正确格上的等价改写是负例，未知候选不训练。UK80格、Iowa91格、18F6格、Packt78格的认证范围未扩大，未认证上游公式与整表业务。

全部人工合成来源作为一个组，另四组为UK、Iowa、18F、Packt。五折每次排除整个来源；来源等权，其内家族/工作簿/候选逐层等权。固定原dev16的100轮HistGradientBoosting、p≥0.90、差距≥0.05；训练和推理统一float32。每折训练只能打开自己的训练标签，候选提取禁止标签、作者脚本及oracle读取。先锁特征，再标注；先锁模型和预测，再独立进程评分。

候选共1,861,162条：18,022正例、1,284,155负例、558,985未知。这是候选条数，不是独立工作簿或错误格数。原SG/FG/dev11的全流程对照沿用已冻结、输入哈希匹配的dev16/dev17上游；本轮计时不冒充重新运行原SG/FG的总成本。
