# dev16：分组训练候选选择器实测（2026-10-18）

## 结果与决定

完成首个可训练候选选择实验：从原论文和已有改进版的冻结输出构建候选池，用HistGradientBoostingClassifier学习候选是否能正确修复。家族分组交叉拟合中，保留dev11再补充学习器建议，新增178个正确修复和1个误修，覆盖率78.82%→79.81%；整个来源留出中，精确率降为72.94%，不能采用。主模型继续保持dev11完整AST保护的dev6/dev8核心，最终目标仍active。

这些是已揭示开发语料的跨组诊断：167个人工合成输入与同一个英国LCOE文件的16个开发副本，共183输入、17,995个已标注错误、43,879个去重候选。10个登记家族不等于10个独立来源；所有人工合成归为一个作者来源，LCOE归为另一个已排除公开来源。不存在新最终数据、自然错误真值对或最终合格来源的增加。

## 划分和真实跨来源失败

家族分组5折：profit整组包含regression/stress/tradeoff，其余按原家族登记；LCOE全部副本同组。家族名SHA256排序后轮流分配5折，不按行随机拆分。独立核对全部输入语义元数据，7组语义重复案例不跨折；同输入异真值的冲突对仍保留计分。家族划分仍有同一作者和注入机制共性，不能代替来源独立验证。

来源留出2折：167个人工合成输入整组留出时，只用LCOE训练；16个LCOE输入整组留出时，只用人工合成训练。保留主候选并补充模式在人工合成组得到17,722正确、6,575错误，精确率72.94%、覆盖99.14%；LCOE组零建议、覆盖0%，精确率未定义。混合后的98.48%覆盖掩盖了LCOE完全失败，不能当作接近最终达标。

## 候选池与置信度诊断

独立上界审计：候选池含17,937/17,995个已知错误的正确候选，可达覆盖上界99.68%。这是读取答案后的oracle上界，不是模型成绩，也不保证各类别双90%。58个无正确候选的错误来自adversarial 25格与LCOE 33格；LCOE局部候选池上界仍仅86/119=72.27%。

因此在已有人工合成语料中，优先缺口是候选选择和错误置信度；LCOE还需独立业务证据和新候选。来源留出中概率≥0.9的23,645个已知、语法受支持候选实际仅72.21%正确。所有概率诊断在锁预测后完成，未改阈值、重标标签、筛选有利折或重新选择模型。未知只从概率校准诊断中排除，仍保留在修复精确率分母。

## 训练、隔离与可复现性

1. 单独的无答案进程提取101维特征：候选来源、原模型分数、完整AST支持、引用/运算编辑、同行/同列/显式平行表支持、可见局部文本指示。路径、ID、绝对坐标、来源/家族/场景不进入向量；原始文本只转为预先固定词表的指示量。
2. 特征先锁定，再在作者进程准备标签与分组；未知不训练。每家族总权重相同，家族内工作簿等权，工作簿内候选等权。零候选工作簿不贡献训练样本，但留在评分分母。
3. 固定100轮、learning_rate=0.08、最多15叶、深度6、min_samples_leaf=20、l2=1、early_stopping=False、seed=1618。固定阈值0.90及第一/第二候选差≥0.05，输出仍须原式与候选完整AST受支持。没有利用留出行调参或早停。
4. 每折训练只允许读取该折训练标签；其他折标签、整体答案及作者准备代码的读取会实际被审计钩子拒绝。所有训练标签路径记录在预测锁，留出标签读取记录为空。
5. 训练/预测结束后锁7个模型、366个案例预测、全部概率、源文件和输入哈希，然后另进程读取整体答案评分。旧实验与原论文源码未改。
6. 全套165项测试通过。独立重算43,879个候选标签、1,098个案例/方法统计和所有分组汇总。完整重建43,879条特征，均与冻结值一致；7组重复输入×2种划分×3种方法共42项建议一致性检查通过。
7. 重新加载7个冻结模型重放366个预测，全部概率和建议逐项一致。另按固定seed重新训练全部7折，全部概率和建议仍完全一致，过程未读取留出答案。

准备阶段发现旧语义指纹工具不支持SharedFormulaRegion；新增纯观察指纹实现支持dataclass并测试，旧工具和实验不改。该修复发生在分组锁与模型训练前。
