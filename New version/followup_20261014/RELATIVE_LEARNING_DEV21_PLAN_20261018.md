# dev21 候选相对原式的偏好学习

诊断dev20冻结结果后发现：3,605错误的正确候选排第一但低于0.90，220错误排错；54缺正确候选、3可见性不合格，dev11修复14,184，学习器补7。没有由两个正确候选之间差距不足造成的拒绝。本轮研究相对原式建模，不通过降低阈值选择开发结果。

保留原论文0.3.0、主候选dev11、dev18–20的输入/候选/标签/来源折/参数/锁。对213案例中有候选的目标，使用相同Context、角色及单位代码提取“保留原式”的356维向量k，不新增输出公式候选，也不从答案定位目标。先禁止标签访问生成并锁定k，再训练。保留原始1,861,162候选及其顺序。

训练只读当前折原dev18允许的训练候选标签。对每个工作簿/单元格保留所有已认证正候选；负候选按既有不含答案的候选ID排序最多保留32条，未知不训练。每条(c,k)生成两条：[k,c-k]标签y，[k,k-c]标签1-y。语境k始终相同，交换的是候选差值；数据不是新增独立业务样本。来源/家族/工作簿/所选候选逐层等权，两个方向各一半，因此类别总权重均为1/2。只用于训练内压缩，推理与评分仍全量，没有按分数抽样。使用同一100轮HGB参数，不调阈值、迭代数或来源留出结果。

推理相对偏好=(p([k,c-k])+1-p([k,k-c]))/2，确保交换反对称。0向量为0.5，不表示修改优于保留；此值不是校准的业务正确概率。保持p>=0.90、差距>=0.05、完整AST/可见性门和dev20选择后单位拒绝门。保存未过滤/过滤及保留dev11三种建议，全部有序偏好值与原单位拒绝证据锁定后才评分。

这是表示、训练取样和类别平衡共同改变的开发实验，不称单特征因果消融。相对原式是显式拒答比较，不证明工作簿意图。保留正确格、业务例外、共错及隐藏错误；不因低覆盖删掉来源。旧公开来源永久属于开发，最终6新来源/15家族、自然错误配对及三类双90%目标不变。

验证：原式特征能从可见工作簿重建、候选有序绑定/空矩阵/浮点检查、镜像权重与训练标签隔离、零差值和反对称偏好、阈值/差距/单位门、所有213例概率及建议重放、独立计数。输入/模型/特征锁必须核验，及时提交GitHub。
