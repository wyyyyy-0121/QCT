# dev22：有认证方向的偏好训练，五来源实验预登记

dev21完整五来源实验未提升覆盖。下一步检验一个目标构造假设：正确性都为0的候选和原式没有可认证的优劣顺序，不能把其差值镜像成有方向的偏好监督。

已实现`certified_preferences_dev22.py`的纯训练对构造器，并增加4项边界测试。每个目标必须显式提供一个原式keep选项及正确/错误/未知状态；构造器不推断标签、不读取工作簿或答案。只比较认证正确与认证错误选项，保存精确反向镜像；双方正确、双方错误和含未知的比较不产生偏好标签。每格按不含答案的候选ID排序保留最多32个错误候选，另保留已认证错误原式；全部认证正选项保留。未知仍存在于全量推理候选池和评分分母，不能从预测流程中删除。

构造器与标签映射的7项测试已经通过。接下来复用dev21已经锁定的356维原式/候选无标签特征，独立准备并锁定dev22逐折认证状态和配对，再进行五来源训练、全213例预测锁定、单独评分和重放。在首个预测锁之前不得读取本轮留出评分；结果写入另行报告，不能称为已有性能提升。dev21和原模型的现有锁均保留。

接入前必须完成：

1. 在单独准备进程中，根据已有可靠认证范围建立逐折训练原式状态，答案状态不可靠则为unknown。禁止用“没有找到正确候选”推断原式正确或错误。新状态文件有来源、认证范围、训练case名单及SHA，预测器仅允许当前折训练文件。
2. 冻结原式状态、配对规则和全量有序无标签特征；核对正负及未知计数，证实没有双方错误样本被赋予虚构方向。保持来源/家族/工作簿隔离，镜像两向权重相同。
3. 首个对照沿用dev21的输入、候选池、356维特征、100轮HGB参数、0.90/0.05阈值和所有保护门。用`[原式上下文, 左公式特征−右公式特征]`训练认证比较，推理仍比较候选与保留原式。目标与训练取样一起变化，不能宣称单因素因果消融。
4. 如要校准，单独预登记并仅在当前训练来源内部进行，不能从来源留出分数选择阈值。全213例锁预测后才另进程评分，报告每来源与原基线/dev20/dev21的变化及全部错误/未知建议。

自然错误配对、最终6新来源/15家族及三类双90%仍为原目标，不由此构造器替代。研究文件继续位于`New version`；原论文模型和`/home/ayaka/code`不修改。

## 接入时的标签范围约束

旧dev18的候选0标签是“非成功修复”，不能普遍解释成公式错误。dev22只在已标错误格继承已经独立审计的候选接受标签；作者合成沿用冻结评分器的严格原式字符串目标，公开局部关系沿用其原有等价判定。对已认证正确格，原式为1，但候选的旧0一律转为unknown，除非候选字面等于认证期望公式而为1；不引入未经验证的新公式oracle。此保守映射意味着部分正确格没有可训练的对比，仍全部保留于预测/评分，必须单独报告。

原式状态由已认证范围及错误台账给出：范围外unknown、范围内错误格0、其余1；绝不因候选池没有正例而推断状态。所有状态在独立准备进程中锁定，训练仅允许读取当前来源折的训练文件。原有dev18评分标签及dev21锁不改动。

## 冻结的训练实现

训练输入为显式有向配对，表示为`[该目标的原式特征, 左公式特征-右公式特征]`；每个认证正/负组合保留两向，减法用float32、随后写入float64磁盘映射矩阵以避免HGB额外复制。左右选项可为原式或候选，必须来自同一目标。权重仍按来源、家族、case分层均衡，配对镜像权重完全相等。每折100轮HGB，参数和随机种子均继承dev21；推理调用原dev21候选对原式的双向概率函数、0.90阈值、0.05间隔、原单位门及dev11建议合并策略。新增的候选间比较与目标取样是共同变化，解释为目标构造实验。

模型进程只准读取当前折训练标签，禁止author_case_states、author_case_pairs、其他折训练标签、heldout_truth和case_labels。准备锁绑定原标签锁、逐折清单及原式特征锁；预测锁绑定本轮准备锁、所有模型/预测/概率与运行记录。独立审计从认证状态重建期望配对并核验镜像、未知排除、错误对错误排除、折隔离和权重，之后才运行训练。清洁目标没有认证反例的数量单独报告，不能把它们从推理或评分中剔除。主比较同时列出dev11、dev20、dev21和dev22；是否采用不能以调低本轮阈值换取覆盖。
