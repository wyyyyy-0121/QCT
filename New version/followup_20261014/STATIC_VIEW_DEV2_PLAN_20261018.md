# OOXML静态分析视图开发实验

只使用此前已揭示、整个来源已排除的public01、public05、public06、public07。public06/07因xlsm被论文SG拒绝，public01为普通xlsx一致性对照，public05为答案表隔离拒绝对照。不得获取任何保留的最终验证工作簿。

目标是验证读取边界，不是证明修复质量提升。使用原论文源码和冻结dev11，只在新增适配层生成静态分析副本。复制所有worksheet XML、workbook XML、共享字符串、样式和缓存；移除VBA载荷及声明，修改主工作簿包类型。所有改变、移除和未改变部件逐项哈希记录。不启动Office，不执行宏，不重新计算工作簿。此副本只供静态分析，不声称在Excel中功能等价。

遇到潜在答案/标签工作表，在读取单元格或sharedStrings前拒绝整个输入。不支持xls/xlsb、外部工作簿关系、ActiveX/OLE、签名及旧宏工作表的包，保留失败，不能从覆盖分母删除。只接受普通xlsx/xlsm静态单元格情形；宏产生的数据、UDF和外部连接尚未支持。

所有四例都登记和执行，成功或失败均记录。两个原始xlsm的原版SG后缀拒绝单独报告；适配后论文和dev11均使用同一副本，不把适配收益当成候选选择算法的收益。普通xlsx对照须与已锁定dev10论文输出、dev11输出逐行完全一致。

运行前冻结新模块、运行器、测试与原论文源码哈希；在独立进程执行每例，保留180秒超时。记录公式数、独立原始公式声明数、缺失载入声明、求值失败、实际修改建议、CPU/wall/RSS和GPU使用情况。没有业务标签，精确率和覆盖率记未定义。另进程用原XML与openpyxl复核全部单元格/公式/可见性，并重新生成视图及重放预测。

11项新增测试已覆盖：原文件不可变、工作表/隐藏行列/缓存/共享及数组公式字节保留、确定性、原xlsx保留、拒绝覆盖、保护表预检、外链/未知二进制/DTD/越界关系及xls/xlsb拒绝。测试不替代实际公开工作簿核查。本轮不增加最终来源与家族数，目标保持active。
