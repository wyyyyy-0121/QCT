# dev17：新增三个已有公开开发来源的完整文件实验

上一轮已证实dev16来源留出失败，不能采用。先扩展真实开发业务关系，再评价候选与选择的缺口，不通过复用预留最终来源调参。只用已接触并整体排除最终验证的public03 Iowa现金流、public09 18F软件成本、public10 Packt项目融资原文件；原件、旧锁和code目录不改。

每个来源固定10场景：原件干净、填入场景输入干净、孤立运算、孤立引用、系数错误、整个主要区域共同错误、多区域混合、带可见说明的合法例外、隐藏错误区域、错误文字说明+真实错误。共30个完整工作簿，不视为30个独立来源或模板家族。错误说明仍计入，未知建议不删分母。

标签范围先由业务标题/单位及可核查关系登记，再核对原式：Iowa现金流的逐项跨期合计、流入/流出汇总、净现金流、期初/累计现金流；18F四项年度维护比例合计及比例×基准年度成本；Packt借款的期初=上期结余、期末=期初+借款+负数还本。Packt PPMT为负数还本，此处不推断与其相反的扣减符号；不验证PPMT/跨表上游公式本身。范围外不默认正确，公开原表不是业务答案文件。

独立oracle使用openpyxl Tokenizer与精确SymPy表达式；支持有限+-*/及SUM范围，数值输入视作独立符号而非把当前值相等当关系证明。SUM内空白/文本忽略，普通算术文本拒绝；不内联上游公式，避免循环重写被误当正确。另保存不同错误公式的有理数反例值；它是关系差异见证，不是Excel整表重算。准备时可在另进程用LibreOffice检查场景可重算性；不把工具一致性当业务正确证据。

先运行论文原SG/FG完整流程及dev11、dev15同输入对照。加一个不学习标签的同行/同列候选池：每轴±1/2个可见公式平移，满足至少2个相同支持才保留，两个轴冲突全保留供复核。dev16冻结来源折模型只作新来源推理诊断；不能挑选某个旧折做最优结果。旧全部人工合成训练、LCOE留出的那个模型用于三个新增来源，保持既有0.90概率及0.05差距阈值。来源训练模型没有接触新增业务标签，但整个开发方案已受旧结果启发，仍不能称独立最终验证。

为让单元格候选与旧schema一致，候选来源新增peer时不冒充paper/dev11等，旧101维中origin指示全0；其邻居支持特征正常计算。未知候选不训练。先锁源码、计划、输入、预测及候选，然后独立评分，逐来源报告全部建议、确认正确、确认错误、未知、覆盖率、候选上界。无候选/弃答/隐藏/不支持均计入已标注错误分母，不能仅比较会输出的样本。

本轮先完成新来源可核查开发标签、真实全流程对照、冻结学习器迁移失败/收益及候选缺口证据。只有新增多来源训练具备足够证据时，才另外预登记并新增版本训练；不改已冻结dev16。最终来源/家族仍0，自然错误配对和三类独立双90%目标保持active。

准备后、预测前补充：Packt的isolated_reference把SUM起点从第8行扩到第7行，而第7行为空；独立关系oracle确认这是语义中性变化，已保留为零错误反例，不删除或改成更有利的注入。全部建议精确率的正确分子只包含真正错误被正确修复；对正确格输出代数等价但文本不同的建议记为不必要建议，进入分母、不算成功修复。该口径避免无意义改写提高精确率。标签只认证当前空白/文本布局下的局部关系，不认证未来编辑空白格后的行为或未来复制模式。
