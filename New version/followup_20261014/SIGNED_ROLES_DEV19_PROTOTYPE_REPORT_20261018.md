# dev19角色与符号特征原型：尚无修复成绩

为解决dev18把正确减项误改加项的12个反例，新增17类有限英文角色特征及加项/减项/非线性引用上下文。记录目标角色、原式/候选引用角色及差异，不输出修复建议。SUM有界展开；不确定的乘除符号不推断；PPMT/IPMT只记上游语法存在，不假定结果永远为负。
