# dev25：外层来源完全隔离的嵌套修复成功率校准

本登记在任何dev25训练前冻结。dev24的结果仅用于提出研究假设，绝不把其外层预测当内层校准样本，也不从外层答案选择阈值。主候选仍dev11，本实验不能替代最终三类独立双90%。

## 固定排序器与真正的内层预测

保留dev24相对排序器的同一356维公式特征、712维配对表示、全1,861,162候选、五个整来源外层折、HGB100轮参数与seed1618。最终外层排序采用dev24已经锁定的五个相对模型，逐个验证模型SHA、训练来源及上游锁；重算其外层概率，不读取旧外层评分或概率文件作为校准输入。

对每个外层来源A，四个训练来源分别作为内层验证来源B；内层模型仅训练其余三个来源。对无序来源对{A,B}只训练一次，保存对A与B的全部候选概率；因此共有10个新内层模型而非20个重复训练。A的校准只准使用该模型对B的输出，B的校准只准使用对A的输出。来源对两端、训练case及标签SHA均锁定并独立审计。不能把仅排除B但训练包含A的旧模型当A的内层模型。

内层训练复用dev24已独立认证的逐格选项，从认证1与0构造镜像相对配对，unknown不训练。取样、来源/家族/case权重、float32特征及float64磁盘矩阵与dev24一致。未取样候选、unknown及不支持目标保留推理与最终评分。

## 校准对象、目标与固定规则

先对每格eligible候选按原始偏好降序、公式字典序取第一；无eligible则无可输出项。相对第二eligible的原始分数差距至少0.05，并通过固定单位拒绝门，才进入校准。候选不递补。这些步骤不依赖标签，不应用原始0.90阈值。

校准只针对上述首位候选的原始偏好，使用一维非递减加权isotonic regression，y来自原dev18已审“成功修复”标签：错误格可接受修复为1，清洁格任何改写为0，错误格不可接受改写为0，范围外unknown排除拟合并单列计数。不能用dev23数值等价1代替修复成功1，也不能将缺失/unknown当负例。仅使用外层训练来源，来源/家族/case权重按拟合中已知首选行重新均衡。

固定`increasing=True, y_min=0, y_max=1, out_of_bounds='nan'`，不得外推到内层已知分数范围之外。若无两种标签或少于两个已知来源，记校准证据不足并全部拒答，不改为猜测常数概率。至少两来源并不证明跨来源校准有效，只是本次预先固定的最低拟合条件。

推理保持原排序及原始0.05候选差距，首位候选校准值必须>=0.90；非有限/范围外或证据不足拒答。校准平台区不重新排序，也不把概率差0.05代替原始差距。固定AST/可见性/单位门不变。记录原始分数、原始第二候选分数及校准分数，不将校准分数称为已证明的业务概率。

报告dev11、校准单独、dev11优先加校准、原始0.90规则单独、dev11加原始规则；合并不覆盖dev11已有格。必须核对原始规则与dev24相对臂完全一致。

## 阶段隔离、锁和复现

1. 作者进程从已锁dev24逐例选项准备10份三来源训练折；外层校准目标直接绑定dev18当前外层训练标签文件SHA，只是预先准备，不给内层进程读取。
2. 内层进程预检只能读取可见特征与锁元数据，禁止任何标签正文哈希。训练时只允许当前三来源训练文件；禁止author、case/heldout答案、校准训练文件及旧dev24预测/评分读取。保存全部10模型及双端候选概率后锁定。
3. 另一个校准/外层预测进程在内层预测锁通过后，逐外层只读自己的四来源修复标签。严格检查每条校准预测模型未见A或B、每个来源/case均在本外层训练中。读完本折、训练校准器并推理本外层后释放标签数据。
4. 全213例外层输出锁定后，另进程读取旧全局答案评分。未知建议仍计精确率分母，18,073错误保留覆盖分母；零建议精确率N/A。按来源/家族/场景报告。

作者独立重建三来源配对及权重；锁后独立重建首位选择、成功标签、校准权重及isotonic单调分段，并核对实测读文件记录。独立逐建议计数、全部内层/外层概率重放、原始dev24一致性和历史锁均为必须验证项。不得仅用一个小烟雾测试支持完整复现。训练临时矩阵自动清理，推理模型/校准器、环境、参数、时间与峰值内存全部保存。

本轮不搜索超参数、校准器类型、分数变换或门槛；任何后续变更另行登记。最终至少6新来源、15家族、可靠自然错误配对以及三类各双90%保持原目标，当前开发五来源不计入最终资格。
