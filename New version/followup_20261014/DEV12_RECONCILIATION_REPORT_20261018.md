# dev12 可见核对关系开发实验（2026-10-18）

## 结论

显式核对关系可以帮助筛选有限候选，但不能证明控制值真实，也不能证明数值相同的公式在其他输入上正确。本轮不满足双90%，不作为已达标的新主模型。没有声明的107个历史工作簿输出行完全不变；原有漏修和合法例外误建议仍未解决。

## 数据与公平对照

- 六类作者编写的计算场景：现金结转、材料守恒、工时汇总、加权计费、库存结转、单位转换；每类10个场景，共60个工作簿、2,640个公式格，其中102个注入错误。
- 干净、孤立错误、共享错误、合法例外、缺声明、错误控制值、目标派生控制、多候选同值、多错误、隐藏控制均保留。六类采用同一生成器和近似布局，不代表六个独立来源或六个真正独立抽样家族。
- 业务输出与声明先编写，错误之后注入；错误控制值是特意保留的反例。独立 Python AST + Fraction 校验2,400个正确输出与102个错误的静默数值偏差，评分进程重新校验输入公式、参考值和注入差异。
- 同一工作簿同时提供给原论文、dev11和dev12；原论文与dev11不能理解新增声明，所以这是带额外可读约束的受控辅助能力实验，不是普通电子表格上的通用提升。
- 原论文按实际非空 suggested_formula 且不同于原式计建议，不要求其原始status为propose，避免重犯dev10旧口径漏计问题。正确修复仍按参考公式精确匹配计数。

## 后续决策

本轮证据支持保留“显式声明辅助筛选”作为实验分支，不支持把它作为主任务双90%的解决方案。下一步的核心仍是工作簿自身可核查的业务证据、减少未知领域的过度弃答，以及公开自然错误的可靠标签。新增同布局样例或重复开发循环不能替代独立来源验证。
