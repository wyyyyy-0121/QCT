# dev30：可见角色规则新增28个正确修复，但无标注合法调整仍会误改

本轮实现并实际评分四类标准财务关系规则，从可见标题动态绑定输入地址；主动输出修复建议，全部计入分母。旧213例新增28正确、0新增错误，合并开发覆盖78.4817%→78.6366%。但独立列出的新开发控制只有75%精确率、60%覆盖，8个无标注合法调整被误改。规则未采用为主模型，未建立新来源泛化收益或最终双90%达标。

## 固定实现

新模块`visible_relations_dev30.py`使用以下预登记假设：净现金流＝总现金流入−总现金流出；年度基准成本百分比＝范围内各项成本百分比之和；年度成本＝年度百分比×有符号年度基准成本；期初余额＝前一列期末余额。没有读取来源ID、工作表名称、固定地址、作者oracle或真值文件作为输入。

角色标题须在同表唯一，输入绑定同列；期初/期末要求相邻可见单位相同。重复角色、隐藏必要角色/输入/输出、可见例外说明或未验证完整指令句阻断新增建议。不猜测还本正负，也不把可见标题叫作作者意图证明。

新增有界精确Fraction多项式比较器，避免把SUM/普通加减、前导正号、括号等已有等价写法误当错误。SUM忽略当前已知文本/空白，未缓存公式保持符号变量。复杂函数和不支持表达式明确拒绝。原论文、dev11及全部旧锁未改；合并臂保留dev11优先、每格最多一条，不修改原文件。
