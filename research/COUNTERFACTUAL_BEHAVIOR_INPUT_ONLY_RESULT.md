## 范围

本实验从冻结的 607 个公开 input-only 工作簿、219 个结构组中按哈希各选一簿，
再按结构组哈希选择编辑类型、目标和单步 AST 注入。选择过程不读取 detector 分数、
行为适用性或反向候选覆盖；原公式只在选择完成后作为已知反向编辑用于评分。

这是一项公开反事实开发实验。原工作簿不保证无错误，因此“恢复原公式”不是作者意图
或真实修复正确性的证明；本实验也不评价全工作簿错误源定位。

统一候选池另在已揭晓的 480 个 V5-Core 同源合成错误上做了条件覆盖回放：AST 24
加 peer 8 的 `recall@32` 为 480/480，AST 单独覆盖 400/480，80 个绝对引用错误由
peer 补足。peer 单独也覆盖 480/480，且正确候选通常有 16 个同方向投票，这恰好说明
生成器与规则化公式块高度同构；该满分只作候选生成工程检查，不是定位或泛化证据。

## 结果

| 开发门 | 结果 | 状态 |
| --- | ---: | --- |
| eligible 结构组至少 80 | 18 | 失败 |
| 至少 3 类各有 15 个 eligible 组 | 9 / 4 / 3 / 2 | 失败 |
| 原表行为异常率不超过 10% | 6/18 = 33.33% | 失败 |
| 注入后行为分数上升至少 65% | 12/18 = 66.67% | 通过 |
| 注入后行为异常率至少 50% | 14/18 = 77.78% | 通过 |
| 行为候选 Top-1 至少 60% | 12/18 = 66.67% | 通过 |
| 相对静态公式基线具有互补增量 | -5.56 pp；独赢 1、独输 2 | 失败 |

133 个工作簿可生成指定注入，统一候选池在其中 128 个恢复原公式；125 个有 AST
来源、67 个有 peer 来源。行为机制只有 18 个共同可比较组，静态公式基线在同一集合
达到 13/18 = 72.22%，高于行为方法的 12/18。

完整实验以 24 workers 重算两次，两份 JSON 逐字节一致，SHA-256 同为上述值。

## 决定

当前局部反事实响应只能在很窄的连续同伴区域适用，同时产生不可接受的原表异常率，
且候选选择不优于更简单的静态公式指纹。该路线不进入全工作簿定位桥接实验，不作为
`V5-R1` 组件，也不再在这 219 组上调整 peer 数、阈值或连续权重。

`V4-R1` 仍是唯一冻结主排序器。后续候选机制必须形成全工作簿排名、使用不同于局部
peer 响应一致性的证据，并在接触两套 `240+120` 前完成独立的公开开发与候选锁。
