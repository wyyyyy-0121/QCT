## 3. 连续失败的共同原因

### 3.1 代理目标错误

过去各线依次把以下信号当作真实源错误的替代：

- 合成生成器中的公式制度和例外位置；
- 一套跨工作簿固定的异常加权分数；
- 候选替换后内部规律或下游数值的恢复；
- 单格语义与邻格不一致。

这些信号都可能与错误相关，但也会在合法例外、多个正常公式制度、孤立汇总和大规模
错误块中出现。它们不能单独识别业务语义上的正确公式。

### 3.2 把错误风险与影响范围混成一个分数

现有图通道把结构异常和后代数量直接相乘。后代多说明审查价值或潜在损失大，不说明
该公式更可能错误。新方向必须分开：

- `defect risk`：可见上下文是否支持“此公式偏离可重建角色”；
- `impact`：若该格错误，可能影响多少下游区域和关键汇点；
- `review utility`：在固定人工预算下如何兼顾风险、影响和假设覆盖。

图影响不能把低风险格直接包装成高置信错误。

### 3.3 单格排名忽略了真实的区域结构

Enron 含多源错误块，合法工作簿也可能含交替或并列公式制度。对大块同分格用地址打破
并列没有证据意义。新模型应先形成公式区域和角色假设，再输出确定的完整单格排名；
Top-5 应避免把全部预算浪费在同一个等价区域。

### 3.4 合成数据与模型机制同构

V5-Core 和 V4.3/V6 已证明：标签物理隔离并不自动产生机制独立性。以后数据审计必须
同时检查原工作簿、模板、相对正确-错误公式对、公式角色和区域制度是否跨划分重合。

### 3.5 学术比较仍不完整

仓库中的 `excelint_like`、`warder_like` 等是思想级代理，不是原作者工具。没有在共同
支持子集上运行原实现或经验证的忠实复现，就不能声称超越 ExceLint、CUSTODES、
WARDER 或 SEDMR。继任 V4 和超过公开学术方法是两条不同的证据链。

## 4. core-reset-b 的可证伪问题

> 在只给出单个工作簿、没有期望输出、通过/失败测试、正确公式或错误类型时，能否先
> 从行、列、矩形区域和依赖角色独立地重建公式假设，以角色稳定性排除合法多制度，
> 再把校准后的缺陷风险与图影响分开，在固定五格人工预算下稳定超过 V4？

该问题不预设答案。若可见证据不能区分错误和合法例外，就必须输出
`abstain_ambiguous` 或 `unsupported`，不能用图重要性填补缺失的正确性证据。

候选修复只在排名之后生成，用于解释“哪些同伴支持什么替代公式”；候选替换后的数值
变化不得再决定基础错误风险。

## 5. 文献与原创性边界

以下部分明确来自既有研究，不主张原创：

- ExceLint 的相对引用、矩形区域、熵和邻域修复；
- CUSTODES 的强/弱特征与两阶段公式角色聚类；
- WARDER 的 validity-based 聚类修正；
- AmCheck、LaMirage、FLAME 和相关工作的公式重建或修复；
- spreadsheet SFL 的依赖锥和故障定位；
- SEDMR 的蜕变关系；
- selective prediction 的弃权、coverage 和 risk-coverage；
- 通用的集成、排序融合、校准和多样性选择。

只有在补充文献门并通过对应消融后，才可检验一个窄组合性主张：

> 区域级多上下文公式假设、合法制度稳定性、缺陷风险/图影响分离和固定预算假设覆盖，
> 是否能改善无输出真值的静默公式源审查。

“组合不同”本身不是创新；独立结果、与简单组合的增量和清晰失败边界三者缺一不可。

## 6. 分阶段计划

### Phase 0：证据和分组审计

先创建一份只读数据账本，不运行新排名：

1. 为公开 60+30 以原始工作簿内容哈希建立组，并把错误版与对应原表放在同组；
2. 为 Enron 以工作簿哈希分组，同工作簿的多个事件不跨折；
3. 审计历史 100 的生成来源、模板关系和结构近重复；找不到原模板 ID 时明确按 100 个
   工作簿分组，并报告不能排除同源生成的限制；
4. 将公式布局、相对公式多重集、依赖图摘要和工作表结构纳入近重复审计；
5. 证明旧试用包和新保管人包均未被读取；
6. 固定开发数据、工程数据、revealed-trial 和最终盲测四种角色。

**Gate 0：** 分组键、近重复规则、数据用途和标签读取边界全部可复算，否则停止。

### Phase 1：原文方法卡与真实基线门

1. 从已核全文为 ExceLint、CUSTODES、WARDER、AmCheck、SEDMR、spreadsheet SFL、
   LaMirage/FLAME 和 selective prediction 建立输入、输出、数据、指标、实现可得性方法卡；
2. 补检“公式角色重建、校准异常检测、风险-影响排序、预算多样性选择”的直接邻居；
3. 优先运行原 ExceLint。其公开版本依赖 Windows、Excel 和 Visual Studio，Linux 只
   负责准备共同工作簿清单、哈希和结果转换；
4. CUSTODES、WARDER、SEDMR 若没有可运行原实现，只能做经论文样例验证的
   `reimplementation`，不得去掉后缀；
5. 学术比较只使用共同支持案例和方法原论文对应指标；检测 F1 不与源定位 MRR 混比。

**Gate 1：** 每个论文主张都有原文依据和可比指标。原实现不可得不阻止内部 V4 继任，
但永久阻止“已超过该原工具”的结论。

### Phase 2：可识别性与信息上限审计

本阶段不训练最终模型，也不选择权重。预测函数只接受 `WorkbookModel`，在标签读取前
原子写入完整分片。固定检查：

1. **观察等价类：** 由相对公式、区域角色、局部上下文、依赖角色和语义边界形成的
   无标签签名；报告源格所在等价类大小，禁止把地址排序当作证据；
2. **多上下文重建：** 分别从连续行、连续列、矩形邻域和依赖角色生成留一公式假设，
   记录支持、冲突、稳定性和是否存在稳定替代制度；
3. **通道上限：** V4、公式区域、依赖角色、语义/范围重建的 Top-5 及标签后并集；
   图后代影响单独报告，不计作错误风险通道；
4. **V4 未命中分析：** 逐组判断未命中是存在新增可见信号、五格预算分配失败，还是
   当前输入下不可区分；
5. **控制可分性：** 使用公开错误原表和公开控制表；错误版与原表必须在同一折，防止
   成对泄漏；
6. **分组评估：** 五折按工作簿/模板分组，并做 leave-one-corpus-out；事件宏平均只能
   作为次要结果。

**Gate 2：以下全部满足才允许预注册模型：**

- V4 与新增风险通道的标签后 Top-5 分组宏并集相对 V4 至少 `+10` 个百分点；
- 至少两个主要语料各有至少 `+5` 个百分点的并集余量；
- 至少两个新增证据族各贡献不少于 3 个不同工作簿/模板的独有命中；
- 至少一半 V4 未命中且被并集救回的组，其源格无标签等价类大小不超过 5；
- 仅用训练组确定的保守行动规则在外层测试组达到错误源命中率至少 `30%`、
  acted-error precision 至少 `75%`、控制行动率不超过 `15%`；
- 分片、标签隔离、分组和指标复算全部通过。

失败时终止 `core-reset-b`，不修改通道、不放宽 Top-5、不搜索新权重，也不运行任一
`240+120` 包。

### Phase 3：候选模型预注册

Gate 2 通过后，才固定候选实现：

1. **区域/角色层：** 先按公式结构、布局和依赖角色形成候选区域，再用稳定弱特征
   识别合法交替制度和边界；
2. **假设层：** 每格保留来自行、列、矩形和依赖角色的独立公式假设，不把多个同源
   邻格重复计成独立证据；
3. **风险层：** 用留一重建不一致、支持差距和重采样稳定性形成可校准风险；只允许
   一个低复杂度、特征单调方向已固定的模型，禁止文件名、语料 ID、错误类型和地址；
4. **影响层：** 单独计算后代规模、分支、关键汇点和跨表传播，不进入风险置信度；
5. **预算层：** 先满足高风险，再在风险带内按影响排序，并对同一等价区域去重，确保
   五格覆盖不同错误假设；
6. **行动层：** 输出 `review`、`abstain_ambiguous`、`unsupported`；行动阈值只由
   训练组控制数据固定；
7. **解释层：** 显示观察公式、各上下文假设、支持/冲突、风险、影响和拒绝原因；
   候选修复不能反向修改排名。

预注册同时固定完整排名并列规则、缺失特征处理、最多一次结构修订的故障顺序、全部
消融和停止规则。不得先实现多个复杂模型再挑最好看的结果。

### Phase 4：揭晓开发评估

使用公开 60+30、历史 100 和 Enron 30，全部按 Phase 0 分组。比较：

- V4-R1、V4.3、PSL 静态 60/40；
- 单独 Formula、Graph、Semantic；
- 等权 RRF、固定 `2/2/1`；
- 经验证的 ExceLint/CUSTODES/WARDER/SEDMR 原实现或明确复现；
- `core-reset-b` 完整模型；
- 去区域制度、去多上下文、去风险校准、风险与影响重新混合、去预算去重等消融。

主要指标为工作簿/模板分组宏 Top-1/3/5、MRR、Top-5 人工成本、acted precision、
错误源行动覆盖、控制行动率和 risk-coverage。多源块另报 region hit 和源块覆盖，不能
用多标签事件抬高单源事件均值。

**Gate 3：**

- 分组宏 Top-5 相对 V4 至少 `+5` 个百分点，配对组 bootstrap 区间下界大于 0；
- 配对 MRR 为正，且五个外层折至少四折不下降；
- 任一主要语料 Top-5 不比 V4 下降超过 `5` 个百分点；
- acted-error precision 至少 `75%`，错误源行动覆盖至少 `30%`；
- 控制行动率不超过 `15%`；
- 完整模型相对固定通道、简单 RRF、固定席位和关键消融均有非零增量；
- 所有结果按共同支持集、全部有效集和不支持集分别报告。

只允许按预注册故障顺序做一次结构修订。修订后仍失败即终止，不用旧试用包刷分。

### Phase 5：冻结后旧试用包复现

Gate 3 通过并提交候选锁后，旧 `240+120` 只运行一次：

1. 运行前记录归档、源码、配置、环境和输出目录哈希；
2. 不把该包叫作外部验证；它是 revealed-trial；
3. 运行后无论结果如何都不得修改模型；
4. 使用 Gate 3 的同一性能、安全和分组门槛。

失败即终止 `core-reset-b`，新保管人数据继续不揭晓。

### Phase 6：新保管人最终盲测

只有旧试用包通过，才进入：

1. 双归档预承诺和模板重合审计；
2. 候选锁后释放无标签 PUBLIC；
3. 24 进程生成全部完整排名并锁定；
4. 锁成功后释放 SECRET，一次评分；
5. 按未见模板分组报告 240 错误和 120 控制。

正式 `V5-R1` 至少要求：Top-5 相对 V4 绝对提升 `5` 个百分点、配对 MRR 改善区间
为正、控制行动率不超过 `15%`、主要模板组无系统退化，并通过全部完整性审计。任何
一项失败都保留为负结果，V4 继续作为主模型。

## 7. 两条必须分开的成果线

### 7.1 V4 继任结论

由相同工作簿、相同源标签和相同指标上的 V4 配对比较支持。最终新保管人盲测是这条
结论的最高证据。

### 7.2 公开学术方法比较

只能由原实现或忠实复现、共同支持子集和匹配指标支持。新保管人数据即使通过，也不
自动证明超过未在该数据上运行的公开工具。论文必须分别写这两条结论。

## 8. 若无输出真值任务不可识别

若 Gate 2 失败，结论不是“再调一次参数”，而是当前输入契约的信息不足。此时只允许
另立研究问题，例如最小交互式调试：用户提供一个重要输出格、一个失败/通过标记、
历史正确版本或一条领域约束，再用依赖切片和区分性测试定位。该方向与 GoalDebug、
spreadsheet SFL、MUSSCO 和不变量测试直接重叠，必须使用新名称、新数据和新协议，
不能作为 `core-reset-b` 的补丁。

## 9. 立即执行顺序

1. 提交本复盘文档，不提交中止方向的原型；
2. 实现 Phase 0 数据分组、近重复和证据角色审计；
3. 完成 Phase 1 方法卡与原实现可得性清单；
4. 在任何新模型代码前预注册 Phase 2 的无标签分片和评分器；
5. Gate 2 结果出来后再决定是否实现 `core-reset-b`。

大型运行继续统一使用 24 个进程；运行期间每 10 分钟检查一次完成回执，不高频轮询。
