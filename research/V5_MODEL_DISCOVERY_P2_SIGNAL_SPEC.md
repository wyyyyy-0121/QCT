# model-discovery P2 无标签原子信号规范

日期：2026-08-31  
协议：`formulaguard_model_discovery_label_free_signal_audit_v1`  
状态：P2 实现规范，Gate 2 评分前冻结

## 目的

P2 不训练继任模型，也不读取错误标签。它只回答一个可审计问题：在一个工作簿的
可见公式、布局、格式和依赖图中，哪些局部证据视角彼此支持，哪些案例必须拒绝。
输出的排名是信号审计清单，不是已经通过的 V5。

## 输入边界

`audit_workbook(model)` 只接收 `WorkbookModel`。允许读取公式文本、常量/缓存值、
可解析引用、工作表边界、可见性、数字格式和依赖边。禁止传入或派生：正确公式、
错误版与原表配对、源格、错误类型、通过/失败、语料/模板 ID、文件名语义和任何
SECRET 字段。输入哈希仅用于完整性审计。

## 四个原子视角

1. **同伴偏离（peer）**：在同一行、列、局部邻域和兼容引用形状内，统计将同伴公式
   平移到目标格后得到的候选族。不同轴的支持分别记录，重复同伴不重复计数。
2. **角色离群（role）**：按宽泛运算类型、引用形状、入度/出度带和数字格式形成角色
   桶，报告目标公式族在角色桶中的相对稀有程度和竞争度。
3. **传播影响（impact）**：在固定深度和节点上限内统计后代、汇点和加权可达范围。
   它只能决定同一证据层内的复核次序，不增加缺陷置信度。
4. **透明组合（combined）**：先按证据层和缺陷证据排序，再仅用影响作为同层并列
   的稳定键；不使用 V4 排名，不使用连续拟合权重。

## 状态与候选解释

- `evidence_supported`：一个替代公式有至少两个独立同伴、至少两个证据轴、明确
  支持差，并且竞争制度不接近。
- `ambiguous`：存在多个竞争替代，或只有单一证据轴，不能安全行动。
- `unsupported`：公式不可解析、没有足够同伴，或没有替代证据。
- `impact_only`：传播影响可计算，但缺陷证据不足；不得升级为错误行动。

候选公式是解释性假设，只在排名确定后输出，不能用候选与原表差异证明错误，也不能
反向改写基础排名。每格同时保留 `defect_score`、`impact_score`、候选支持轴和原因码。

## 确定性和完整性

- 覆盖全部公式格；不支持语法保留在完整排名尾部并给出原因。
- 输出四个完整排名和四个不超过五格的去区域复核集合。
- 并列最终使用规范化工作表序号和 A1 地址，仅作为稳定键，不作为证据。
- 每个分片记录输入哈希、配置哈希、协议版本、源码哈希和 `audit_sha256`。
- 所有分片完成后才允许独立评分器读取揭晓标签；P2 运行器本身不接受标签参数。

## 预注册反证检查

实现和评分必须检查：工作表改名、整体平移、无关格式变化、合法多制度、标签置乱、
重复运行、同源同伴去重、缺失分片和重复键。若变换改变了相对信号，或标签置乱仍
产生同等行动率，信号不能进入候选模型。

## Gate 2 输出

评分脚本需要比较 `oracle union`、`oracle selector@5`、固定五格 selector 和实际
选择性行动，并按结构组报告 Top-5、MRR、区域命中、source-block 覆盖、行动精度、
错误源覆盖、控制行动率和 risk-coverage。Oracle 结果只表示信息上限，不能授权模型。

只有固定规则通过 Gate 2A 或 Gate 2B，才允许进入 v3 计划的候选规格阶段；否则转入
最小附加信息研究。
