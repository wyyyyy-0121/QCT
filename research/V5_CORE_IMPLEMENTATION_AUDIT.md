# FormulaGuard V5-Core 实施与证据审计

状态日期：2026-08-28。本文只记录当前可由仓库和短测试证明的事实；大型实验尚未
产生的指标一律标为待验证。

## 1. 已实现且已有直接证据

- 新主排序接口为`formulaguard_v5_core_rule`和`formulaguard_v5_core_learned`；
  `v5_core_scores()`不调用`v4_scores()`形成基础排名。
- 历史`formulaguard_v5`、V5.2和原V6分别保留V4.1、V4.2和V4.3语义，历史
  源码哈希由版本谱系测试保护。
- 所有公式先建立公式制度区域并生成最多32个候选；基础反事实预算为质量最高2个，
  深度预算为质量优先且类别多样的最多8个，最多120格进入深度评估。
- pilot中发现周期族会被单个错误破坏识别；唯一一次开发修订改为稳健槽位众数，
  同周期槽位形成独立候选来源，且合法周期例外只保护与本槽众数一致的公式。
- 结构、因果特异性、图传播恢复和独立复现四个证据族分别输出；规则头使用第二强
  证据的几何平均，并乘合法例外与副作用抑制项。
- 学习头为纯NumPy、符号受限的成对线性排序；L2只比较0.01、0.1、1.0，五折
  按模板族均衡隔离，固定种子20260827，并记录逐模板族留出准确率、源码、训练
  清单、Git提交、标准化参数和权重。
- 学习头报警校准读取全部已评估候选特征，而非规则头选中候选，因此开发校准分数
  与正式学习头推理分数一致。
- 预测进程只能读取公开清单和工作簿；评分器在完成回执、元数据和每个原子分片
  SHA-256全部通过后才读取标签。
- 数据审计证明文件哈希唯一、数量和析因平衡、模板/种子/公式对/图签名跨划分
  隔离；每例原表与错误表只差一个源公式、无显式错误、声明下游值真实改变且传播
  深度可复算。
- 360份干净控制包含12种可复算、签名互异的真实公式结构，240份用于开发校准，
  120份只用于锁定验证。
- 开发阶段生成规则/学习头的八个匹配消融、红队、Enron和完整审计；锁定验证在
  预测成功前只运行不含标签的公开审计。
- 冻结配置锁定模型/训练/评分/第三方脚本、历史源码、方法说明、四层数据清单、
  训练与验证证据、环境和Git提交。工作区不干净、证据缺失或允许验证后调参时拒绝。
- 第三方600例不能由项目生成器自产；仓库外打包器验证独立声明、单公式注入、
  真实传播、六类各100例、人工/半人工及复杂案例门槛。盲测锁验证冻结前PUBLIC
  哈希、秘密承诺和`v5-core-lock`中的冻结配置，评分器再次验证冻结源码。

## 2. 当前短测试证据

- 全仓库131项单元、协议、真实性和历史回归测试通过。
- 修订后的24例工程smoke数据审计通过；规则头Top-5、MRR、Coverage@32和
  精确修复均为100%。
- 学习头工程smoke Top-5、MRR和Coverage@32均为100%，精确修复83.33%。
- 修订后的24份分层干净控制中两头误报率和合法例外误报率均为0%。
- 结果工作簿完成生成和预览，公式错误搜索为0。

这些数字只证明工程和机制链路可运行，不能写成独立验证结论。

## 3. 仍缺失、必须由大型实验产生的证据

1. 修订后的240例pilot重跑：验证候选覆盖、函数/范围弱项、合法例外和学习头
   稳定性；唯一一次机制修正已经使用，不允许再根据pilot修改核心机制。
2. 1200开发错误、360红队、240开发干净控制和Enron回顾性结果；由此固定配置。
3. 480例内部锁定预测、揭标签评分、配对bootstrap、模型选择及冻结回执。
4. 冻结后的100—5000公式性能实验。
5. 第三方600例的冻结前哈希、PUBLIC预测锁、SECRET评分和最终置信区间。

在第3项通过前，V5-Core不能取代V4；第5项完成前，不能声称V5-Core获得第三方
独立验证。若规则头和学习头都不满足晋级门槛，必须保留V4为主模型并报告负结果。
