# FormulaGuard V5-Core R2 方法规格

状态：开发前预登记草案  
方法名：Dual-Null Causal Attribution（DNCA）  
接口名：`formulaguard_v5_core_r2`

## 1. 研究问题

给定只有公式、常量和依赖关系的工作簿，不提供正确输出、通过/失败测试、错误类型、真实源位置或正确公式，输出：

1. 所有公式的完整源错误排名；
2. 诊断状态；
3. 对进入观测不确定集合的公式给出候选修复、安慰剂显著性和传播解释。

R2不调用V4排名，也不以“正确修复进入候选池”为公式能够获得高基础名次的条件。

## 2. 第一空模型：候选无关的观测源归因

对公式节点 \(v\) 计算无标签观测描述：

- 制度内公式残差、行为残差和局部图残差；
- 后代异常的深度衰减覆盖率；
- 异常是否跨越多个直接分支；
- 异常祖先惩罚；
- 入度、出度、后代规模、公式制度和公式复杂度。

原始观测源分数为：

\[
q(v)=\left(0.55a_1(v)+0.20a_2(v)+0.25P(v)\right)
\left(1-0.35A(v)\right),
\]

其中 \(a_1,a_2\) 是公式、行为和局部图残差中最大及第二大值；\(P\) 是后代恢复潜势；\(A\) 是异常祖先强度。

为每个公式寻找制度类型、公式复杂度、入度、出度和后代数量最接近的公式作为观测对照，得到经验尾概率：

\[
p_{obs}(v)=\frac{1+\#\{u\in M(v):q(u)\ge q(v)\}}
{1+|M(v)|}.
\]

基础完整排名按 \(p_{obs}\) 升序、\(q\) 降序排列。地址只用于保证可复现的稳定顺序，不参与分数。

## 3. 观测不确定集合

反事实计算不处理固定Top-N，也不能从任意低位提升公式。集合 \(U\) 只包含与观测第一名无法可靠区分的节点：

- `p_obs <= max(0.25, best_p_obs + 0.10)`；
- `q >= best_q - max(0.05, 1.4826*MAD(q))`；
- 最多12格。

这些常量只可在回顾性开发阶段按预登记网格调节；新锁定验证后不得改变。

## 4. 第二空模型：匹配安慰剂干预

只对 \(U\) 中的公式生成候选并执行深度干预。候选质量不影响基础观测排名。

对公式 \(v\) 的最佳候选计算：

\[
T(v)=\max_c\left[\max(0,D(v,c))(1-H(v,c))
(0.25\times G(v,c))\right],
\]

其中 \(D\) 是局部净能量改善，\(H\) 是局部或全局副作用，\(G\) 是后代恢复覆盖。

安慰剂对照不是同一公式的其他修复，而是观测上匹配的公式，优先执行与最佳候选相同编辑类型的合理候选。得到：

\[
p_{cf}(v)=\frac{1+\#\{u\in M(v):T(u)\ge T(v)\}}
{1+|M(v)|}.
\]

R2不假定两种证据独立，因此不使用Fisher合并。`p_cf`只用于重排 \(U\) 占据的原排名槽位；\(U\) 外公式的相对顺序完全不变。

## 5. 诊断状态

每个工作簿输出以下一种状态：

- `localized`：观测和安慰剂证据均达到冻结门槛，且没有高副作用或并列；
- `review`：存在观测候选，但反事实证据只足以人工复核；
- `abstain_ambiguous`：无观测显著节点、多个节点并列或安慰剂结果不可区分；
- `unsupported_coverage`：解析覆盖或候选覆盖不足，无法做反事实确认。

报警和完整排名分离。即使拒绝报警，仍输出可复核的完整排名。

## 6. 开发与确认数据

### 6.1 回顾性方向筛选集

- Enron 30事件；
- 已揭晓85例；
- 已揭晓480例锁定验证；
- 旧开发、红队和干净表。

允许用于诊断、消融和有限网格调参，所有尝试写入开发日志。这些数据从此不再称为独立或锁定证据。

### 6.2 新机制留出确认集

必须新建且在冻结后才揭晓。划分单位是错误机制与公式变换，而不是行号或种子。至少包含：

- 未见变异机制；
- 源位置跨行、列和工作表；
- 真实工作簿衍生结构；
- 正确候选被故意移除的定位样本；
- 无错误、合法例外、解析不支持和多可疑源场景。

## 7. 预登记开发顺序

1. R2-S：只运行观测源归因，比较候选缺失时的定位稳定性；
2. R2-P：加入匹配安慰剂，但只记录不重排；
3. R2-F：启用不确定集合内重排与拒绝状态；
4. 在全部回顾性集上做一次固定网格选择；
5. 冻结源码、阈值、数据使用记录和Git提交；
6. 在新机制留出集锁定预测并揭盲。

若R2在新确认集不优于V4/V4.3或只在候选覆盖样本上提升，结论必须降级，不再通过同一确认集继续调参。

## 8. 接口隔离

公开函数不得接收或间接读取：

```text
source_cell, error_type, correct_formula, labels,
template_id, instance_id, workbook_filename
```

允许输入只有内存工作簿、候选预算、匹配对照数和已冻结配置。旧V4、V4.x及V5-Core源码与历史结果保持不变。
