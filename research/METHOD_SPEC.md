# FormulaGuard 方法规格（代码与论文的共同定义）

> 状态说明：第 1—5 节记录 v2 GIR 的形成过程；论文主模型使用第 6 节
> 的冻结 v3 定义。两者不得混写。v3 是启发式的反事实诊断责任分数，
> 不是 Pearl 意义上的结构因果模型。

## 1. 任务定义

输入是一份没有正确输出真值的 `.xlsx` 工作簿。系统只读取单元格、公式及其引用关系，输出全部公式单元格的可疑度排序，并为高排名单元格给出候选修复和影响路径。

研究对象是“静默源错误”：错误公式仍能返回数值，但会沿依赖关系传播。生成器保存的源单元格、正确公式和预期输出只供离线评价，绝不传给 FormulaGuard。`SFL-Oracle` 使用失败输出标签，只作为有真值辅助参照，与无真值方法分组报告。

## 2. 公式依赖图

每个公式单元格是有向图节点；若公式 `v` 引用单元格 `u`，建立边 `u -> v`。图用于计算：

- 前驱、后继和全部后代；
- 从源公式到汇总输出的最短传播深度；
- 局部入度、出度和引用形状异常；
- 候选修复后受影响的下游公式。

公式会转换为相对引用指纹。简单工作表名称有无单引号视为等价，绝对引用符号 `$` 单独保留，以识别复制和锚定错误。

## 3. 三类局部异常与工作簿能量

对公式单元格 `v` 定义：

- `A_f(v)`：公式族异常，比较同一局部区域的相对引用指纹；
- `A_g(v)`：图异常，比较局部入度、出度和引用形状；
- `A_b(v)`：行为异常，比较可重算数值、公式族内的稳健偏差及内部一致性约束。

行为分量由两部分构成：

`B = 0.25 * mean(A_b_general) + 0.75 * mean(A_constraint)`

其中内部一致性约束是工作簿中可见的冗余计算，例如“原路径结果 - 独立重算结果”。它不是实验真值，所有方法都可以看到。残差按相对尺度归一化；求值失败记为最大约束异常。

工作簿能量为：

`E(W) = 0.45 * mean(A_f) + 0.25 * mean(A_g) + 0.30 * B`

反事实评价中，行为异常与约束残差共享一次工作簿求值，避免同一候选被重复计算；这只优化速度，不改变分数定义。

## 4. 候选修复

候选不使用正确公式标签，来自两条路径：

1. 将同一方向、同公式族的邻近公式平移到当前单元格；
2. 对当前公式做有界小编辑。

有界编辑覆盖：

- 普通引用与复制偏移；
- `+ - * /` 运算符替换；
- `SUM/AVERAGE/MIN/MAX` 替换；
- 区域起点、终点的行列移动；
- 行列绝对引用 `$` 的添加、删除和复合恢复。

候选必须能解析、引用有效率不低于 80%，并去重、去越界。每个候选记录来源、编辑类型、邻居支持度、编辑距离和引用有效率。主实验保留 Top-15，并设置编辑族配额，防止大量同类候选挤掉其他错误类型：行复制偏移 2、区域终行 2、区域终列 2、运算符 3、聚合函数 3、参数锚定 2，剩余名额按综合质量补齐。

## 5. 图干预责任分数 GIR

局部先验：

`P(v) = 0.45*A_f(v) + 0.25*A_g(v) + 0.30*A_b(v)`

对候选 `r` 临时替换公式后，定义归一化能量改善：

`D(v,r) = max(0, (E(W) - E(W[v <- r])) / max(E(W), eps))`

传播影响归一化到 `[0,1]`：

`I(v) = log(1 + descendants(v)) / log(1 + max_descendants)`

为强调“源责任”而不是下游症状，定义根因因子：

`R(v) = 0.25 + 0.75*I(v)`

若节点是纵向递推块的首个种子公式，边界因子 `U(v)=0.25`，其余为 `1`。于是：

- `P*(v) = P(v) * R(v) * U(v)`；
- `D*(v,r) = D(v,r) * R(v)`；
- `Q*(v,r) = Q(v,r) * R(v)`，但仅在 `D(v,r)>0` 时计入。

默认完整分数为：

`GIR(v,r) = 0.35*P*(v) + 0.50*D*(v,r) + 0.10*D(v,r)*I(v) + 0.05*Q*(v,r)`

单元格分数取其最佳候选；若没有候选降低能量，仍返回最高质量候选供人工查看，但它不会获得反事实改善分。传播影响不再乘整个分数，避免深层节点被无条件放大。

quick 只比较三组预登记外层权重：

- `(0.25, 0.60, 0.10, 0.05)`；
- `(0.35, 0.50, 0.10, 0.05)`；
- `(0.45, 0.40, 0.10, 0.05)`。

选择满足误报与召回约束且验证 MRR 最高的一组；并列时选择中位运行时间更短者。full 只能读取冻结配置，不允许看完测试结果后调参。

## 6. v3：结构自适应反事实责任（CAR）

### 6.1 局部结构可靠度

设 `N(v)` 为单元格 `v` 的同向局部公式邻居，`m(v)` 为邻居中最常见
公式指纹的出现次数。定义：

`coverage(v) = min(1, |N(v)| / 4)`

`consistency(v) = m(v) / |N(v)|`

`rho(v) = coverage(v) * consistency(v)`

`rho` 不是“公式正确概率”，只表示局部复制结构是否足以让图异常获得
较高权重。无邻居时 `rho=0`。

局部权重为：

- `w_f(v)=0.45`；
- `w_g(v)=0.20*rho(v)`；
- `w_b(v)=0.55-0.20*rho(v)`。

三项严格相加为 1。局部先验：

`L(v)=w_f*A_f(v)+w_g*A_g(v)+w_b*A_b(v)`

若单元格是一个纵向公式块的首行，边界因子 `U(v)=0.25`，否则为 1，
得到 `L*(v)=L(v)U(v)`。这一边界规则是工程启发式，不应写成普遍规律。

### 6.2 干预范围

公式数不超过 100 时，对全部公式尝试候选干预；超过 100 时，仅对 `L`
最高的 100 个公式做完整干预，其他公式仍保留先验分数。正式 Enron
报告必须同时给出公式数和 `min(1,100/公式数)`，避免把小表满分外推到
大表。

### 6.3 分量改善与副作用

对候选修复 `r`，分别计算替换前后的四个能量分量：公式 `E_f`、图
`E_g`、一般行为 `E_b` 和内部约束 `E_c`。对每一分量 `j` 定义：

`gain_j=max(0,(E_j-E'_j)/max(E_j,eps))`

`harm_j=max(0,(E'_j-E_j)/max(E_j,eps))`

分量权重为：

- `c_f=0.20`；
- `c_g=0.15*rho(v)`；
- `c_b=0.25`；
- `c_c=0.40`。

原始改善与副作用为：

`G(v,r)=sum_j c_j gain_j`

`H(v,r)=sum_j c_j harm_j`

`N(v,r)=max(0,G(v,r)-0.50H(v,r))`

这里的 `0.50` 是预登记的副作用惩罚，不是从 full 结果回归得到。

### 6.4 传播责任

影响范围：

`I(v)=log(1+|desc(v)|)/log(1+max_u |desc(u)|)`

检查单元格可达率 `C(v)` 由工作表名中出现 `check/audit/control/validation`
的公式单元格计算。结构路径责任为：

`S(v)=0.60I(v)+0.40C(v)`

再计算候选修复在 `v` 及其后代区域内消除异常的比例 `R_d(v,r)`，得到：

`T(v,r)=S(v)R_d(v,r)`

检查表名称规则在合成模板中较容易满足，在真实工作簿中未必存在。因此
`C(v)` 只能作为可选结构线索，不能被描述为普遍的业务语义。当前 full
消融中去掉路径项不改变排名，这是必须报告的负结果。

### 6.5 最终分数

候选质量为 `Q(v,r)`。v3 对候选的最终分数为：

`CAR(v,r)=0.20L*(v)+0.60N(v,r)+0.10N(v,r)T(v,r)+0.10N(v,r)Q(v,r)`

单元格取最佳候选分数。传播与候选质量都必须乘以正的净改善，不能在
候选没有改善工作簿一致性时凭空制造高分。若所有候选净改善为 0，系统
仍可显示一个弱候选供人工检查，但只按先验排序。

### 6.6 名称与创新边界

CAR 的“反事实”含义是可操作的替换实验：假设某个小修复成立，观察
工作簿内部异常是否下降。它没有外部干预数据、完整因果变量集合或可识别
性证明，因此论文使用“反事实诊断责任”而不是“严格因果效应”。创新点
是将候选修复、内部一致性变化和下游区域恢复组合成可审计排序，而不是
首创依赖图、公式聚类或因果推断。

### 6.7 v3 消融

冻结 v3 只保留三个与实现一致的消融：

- 去结构自适应权重；
- 去副作用惩罚；
- 去传播路径责任。

full 结果只支持第一项的增量排名价值；后两项在合成数据上排名不变。
它们可以作为解释信息保留，但不能声称已被独立证明提高定位精度。

## 7. 适用边界

当前解析器支持数值、A1 引用、矩形区域、四则运算、幂、比较，以及 `SUM/AVERAGE/MIN/MAX/COUNT/IF`。暂不支持宏、外部链接、结构化引用、动态数组、命名区域、字符串常量和大量高级 Excel 函数。不支持的真实工作簿必须记录并排除，不能算作定位失败。

## 8. 可复现纪律

- 固定随机种子并记录工作簿 SHA-256；
- `instances.jsonl` 不含源错误和正确公式，标签单独存入 `evaluation_labels.jsonl`；
- 所有指标由 `raw_results.csv` 自动汇总；
- `-like` 基线是透明的思想级复现，不冒充原作者实现；
- v1 单拓扑结果仅作工程基线，论文主结论使用 v2 多拓扑冻结实验和真实语料；
- smoke、topology、sparse 只作短测试与诊断，不写成正式主结论。
- 合成变异器与候选修复器必须运行耦合审计；当前 v3 full 的正确候选
  Coverage@15 与镜像操作匹配率均为 100%，所以合成满分只作为受控机制
  证据，现实泛化结论以 Enron 和独立盲测为准。
