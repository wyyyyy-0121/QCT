# FormulaGuard 方法规格（代码与论文的共同定义）

## 1. 输入与输出

输入是一个不带期望输出值的 `.xlsx` 工作簿。程序只读取单元格、公式和公式引用关系，不使用人工标注的正确结果。输出是全部公式单元格的可疑度排名，并为高排名单元格给出至多若干个候选修复公式。

实验标签只在离线评价时使用，绝不传入 FormulaGuard 排序器。`SFL-Oracle` 是有真值辅助参考，不是理论上界，必须与无真值方法分组报告。

## 2. 三类不一致信号

对公式单元格 `v` 定义：

- `A_f(v)`：公式族不一致。把 A1 引用改写成相对锚点指纹，比较同行、同列近邻的公式族频率。
- `A_g(v)`：图结构不一致。比较局部入度、出度和引用形状。
- `A_b(v)`：行为不一致。用支持公式子集重算，比较局部数值偏离和可计算性。

工作簿总体不一致能量为：

`E(W) = 0.45 * mean(A_f) + 0.25 * mean(A_g) + 0.30 * mean(A_b)`。

权重不是理论常数；主实验固定使用上述预注册值，敏感性实验再比较其他组合，禁止看完测试集结果后悄悄改主权重。

## 3. 候选修复

候选来自两条无需真值的路径：

1. 将邻近同族公式平移到当前单元格；
2. 对当前公式做一次小编辑：运算符替换、聚合函数替换、引用上下左右偏移。

候选只有在至少 80% 的引用能对应已有单元格时才保留，再按邻居支持度和编辑代价排序。当前主实验上限是每个单元格 15 个候选。

## 4. 图干预责任分数 GIR

把候选公式 `r` 临时替换到单元格 `v`，局部重算后得到能量下降：

`DeltaE(v,r) = E(W) - E(W[v <- r])`。

传播影响因子为：

`I(v) = 1 + log(1 + descendants(v)) / log(1 + max_descendants)`。

单个候选的责任贡献为：

`R(v,r) = I(v) * max(0, DeltaE(v,r)) * (1 + 0.05 * support(r)) / (1 + edit_cost(r))`。

最终分数是最佳候选贡献与小比例静态先验之和：

`GIR(v) = max_r R(v,r) + 0.01 * prior(v)`。

静态先验融合公式族、Excel-like、图、行为和 ExceLint-like 信号。它主要用于保留完整排序并减少反事实退化到无意义公式的风险。大表只对静态先验最高的 50 个公式做完整干预，其余公式保留静态分数。

## 5. 适用边界

当前解析器支持数值、A1 引用、矩形区域、四则运算、幂、比较，以及 `SUM/AVERAGE/MIN/MAX/COUNT/IF`。不支持宏、外部链接、结构化表引用、动态数组、命名区域、字符串常量和所有 Excel 函数。遇到不支持语法时必须记录并排除，不能把它算成算法定位失败。

## 6. 可复现纪律

- 合成基准固定种子并记录文件 SHA-256。
- 正确公式、错误公式和源单元格只保存在评价清单，不传给排序器。
- 所有指标由 `raw_results.csv` 自动汇总。
- `-like` 方法只是透明的思想级复现，不能写成原作者官方实现。
- smoke 结果只用于查流程；论文只引用重新生成的 quick/full 与真实语料结果。
