# FormulaGuard 主模型第一性原理复盘与发现优先计划

日期：2026-08-31
状态：当前唯一权威的主模型研究计划；在信号门通过前不授权实现继任模型

## 1. 当前决定

1. `V4-R1` 继续作为唯一冻结主排序器，`V4.2-Review-B` 继续只作为第六复核位。
2. `V4.1-PCG`、`V4.3-Semantic`、初代 `V5-Core`、`V5-Core R2` 和
   `V5-PSL` 的失败或辅助结论保持不变，不通过改名恢复。
3. `core-reset-b` 在模型实现前停止。其 Phase 0 数据分组审计继续有效，但
   “区域/角色重建、风险/影响分离、五格假设覆盖”只降级为待比较的假设族，
   不再是预先选定的架构。
4. 不创建 `core-reset-c`，也不使用新的正式版本号。下一阶段统称
   `model-discovery`；只有最终盲测通过后才允许命名为 `V5-R1`。
5. 旧 `240+120` 试用包和新保管人 `240+120` 均保持未读。前者只能在候选锁后
   运行一次，后者只能在完整预测锁后揭晓标签。
6. 当前未提交的 `formulaguard/evidence_portfolio.py` 仍是中止原型，不是模型、
   不是结果，也不进入本计划提交。

本次重置不是再换一套权重，而是撤回“我们已经知道新核心应该长什么样”的假设。

## 2. 先重新定义问题

### 2.1 原问题有不可识别部分

当前输入只有一份工作簿，没有正确输出、通过/失败测试、历史正确版本、正确公式或
领域约束。对一个孤立公式，观察到 `=SUM(B2:B10)` 并不能判断作者本来想写 `SUM`
还是 `AVERAGE`。同一个可见工作簿可以与多个互相冲突的作者意图同时相容。

因此，不存在能对所有工作簿可靠恢复真实意图的纯无真值排序器。地址并列、图影响或
候选修复都不能补出不存在的信息。新研究必须区分：

- `identifiable`：可见冗余支持一个明显优于替代解释的公式假设；
- `ambiguous`：存在多个稳定、合法且相互竞争的制度；
- `unsupported`：没有足够同伴、依赖角色或可计算关系形成判断；
- `review_only`：能说明影响大，但没有足够证据说明更可能写错。

### 2.2 三个目标必须拆开

1. **缺陷风险**：可见上下文是否支持某格偏离了可重建角色；
2. **传播影响**：若该格错误，可能影响多少下游公式、分支和汇点；
3. **修复可生成性**：能否提出一个有同伴支持的替代公式。

影响大不等于更可能错误，能生成候选也不等于候选正确，替换后内部规律更平滑也不
等于恢复了作者意图。三类输出可以共同服务人工复核，但不能再压成一个未经校准的
“正确概率”。

### 2.3 新的主问题

> 在只观察单个工作簿且没有输出真值时，哪些静默公式错误具有可复算的内部识别
> 证据；系统能否在明确拒绝歧义和不支持案例的同时，以固定五格预算比 V4 找到更多
> 真实源，并保持对合法工作簿的低行动率？

这是一项**选择性、支持感知的审查排序**任务，不再预设“每份工作簿都能定位”。
完整排名仍须输出以便配对评价，但高置信行动只允许覆盖可识别子集。

输入均未读取。

## 4. 历史失败的共同因果链

### 4.1 用代理目标替代作者意图

历史路线依次把生成器制度、全局异常分、内部能量下降、语义一致性和扰动恢复当成
错误正确性的替代。这些信号在合法例外、多制度表、孤立汇总和正常高影响格上也会
出现，因此高合成分数没有迁移到自然工作簿。

### 4.2 先设计模型，再寻找支持它的数据

V5-Core、V6 和 R2 都在受控生成数据上形成了高度完整的机制闭环，但验证生成器与
模型使用了相同公式规律。标签物理隔离成立，机制独立性仍然失败。以后必须先证明
独立信号存在，再选择架构。

### 4.3 把不同审查单位混为单格排名

Enron 包含多源错误块，正常表又可能含交替公式制度。大块同分后按地址排序没有
证据意义；把同一区域的五个近等价格全部放入 Top-5，又浪费固定人工预算。事件、
工作簿、公式区域和单格必须分别评价。

### 4.4 用组件组合替代原创性

区域、公式角色、依赖图、候选生成、蜕变测试、反事实和弃权都有明确前人工作。
“把它们组合起来”本身不构成论文贡献。只有新问题边界、可验证的增量、独立结果和
失败条件同时成立，才可能形成窄而可信的组合性贡献。

### 4.5 版本推进掩盖了研究问题没有变化

过去名称增加得比可识别信息快。今后每个阶段以问题和门槛命名，不以模型版本命名；
失败阶段不通过新版本号继续搜索。

## 5. 文献复用与原创边界

以下经验可以直接复用，但必须引用且不得单独主张原创：

| 机制 | 直接前人 | 本项目允许的用途 |
| --- | --- | --- |
| 相对引用、矩形区域、熵、邻域修复 | ExceLint | 原实现/忠实复现基线；区域假设生成器 |
| AST/依赖强特征、布局/样式弱特征、角色聚类 | CUSTODES | 多制度与公式角色候选 |
| validity-based 聚类细化 | WARDER | 排除不满足角色有效性的簇 |
| 公式重建与修复 | AmCheck、LaMirage、FLAME 等 | 生成解释性假设，不作为正确性真值 |
| 输入扰动、蜕变关系、推断不变量 | SEDMR、Poon、Roy 等 | 独立诊断特征及失败边界 |
| 依赖锥与故障定位 | spreadsheet SFL 等 | 有 oracle 对照；无 oracle 时只描述影响 |
| 拒绝选项、risk-coverage | selective prediction | 评价覆盖与风险，不主张弃权思想首创 |

当前不写任何“新算法已经原创”的句子。发现门通过后，才从实证结果中选择至多一个
候选贡献：

- 多上下文、集合值公式假设能否量化合法制度歧义；
- 冻结排序器的残差救援能否在固定预算内带来可迁移的辅助增量；
- 缺陷风险与传播影响分离能否改善人工复核效用；
- 若均失败，给出无真值任务的经验可识别性边界和最小附加信息需求。

这些都只是候选主张，不是当前结论。

## 6. 数据角色与不可跨越的边界

| 数据 | 角色 | 可以做什么 | 不能做什么 |
| --- | --- | --- | --- |
| Enron 30/25 | 揭晓自然错误开发 | 失败剖析、信号发现、分组交叉验证 | 再称独立外部验证 |
| 公开 60+30 | 揭晓公开机制开发 | 成对原表控制、注入机制、支持范围 | 代表自然错误频率 |
| 历史 100 | 揭晓人工错误开发 | 结构压力、机制分层 | 代表 100 个已知独立模板 |
| 既有内部合成集 | 工程测试 | 回归、复杂公式和错误类型覆盖 | 选择主模型或支撑泛化 |
| 旧 `240+120` | 冻结后 revealed-trial | 候选锁后运行一次 | 调参、模型选择、外部验证 |
| 新保管人 `240+120` | 最终盲测 | 预测锁后一次评分 | 提前读取内容、标签或模板 |

预测接口只能接收工作簿内容。文件名、路径、语料 ID、错误类型、源格、正确公式和
原始正确工作簿不得进入预测。原表只能在标签后用于成对负对照。所有划分继续使用
Phase 0 的结构外层组；同工作簿多事件及错误版/原表不得跨折。

## 7. 新执行路线

### Stage 1：任务契约与真实基线门

在新增任何模型代码前完成：

1. 固定单源、多源块、缺失公式、错误公式、下游症状和合法例外的评价单位；
2. 固定 `identifiable/ambiguous/unsupported/review_only` 的可观察定义；
3. 为 ExceLint、CUSTODES、WARDER、AmCheck、SEDMR、SFL、LaMirage/FLAME 和
   selective prediction 建立原文方法卡；
4. 方法卡记录输入、输出、任务、数据、指标、实现可得性、运行环境和许可；
5. 原实现、论文验证的忠实复现和思想级代理使用不同名称；
6. ExceLint 原实现优先在 Windows + Excel 环境复现；Linux 负责公共清单、哈希和
   结果转换。现代 add-in 只有在证明能导出确定排名后才可用于批量比较。

**Gate 1：** 任务单位无歧义，每项学术比较有原文依据和兼容指标。原实现不可得不
阻止内部 V4 继任研究，但永久阻止“超过该原工具”的结论。

### Stage 2：无模型证据图谱

本阶段只实现彼此独立的特征/假设提取器，不训练最终排序器，不选择权重：

1. **矩形区域证据**：ExceLint 风格相对引用和矩形分解；
2. **公式角色证据**：AST/依赖强特征及布局、样式、标签弱特征；
3. **多上下文重建**：分别从行、列、矩形邻域和依赖角色做留一公式假设；
4. **制度歧义证据**：允许多个稳定公式族，记录主假设、替代假设、支持和冲突；
5. **图证据拆分**：结构异常只进入风险候选，后代数、分支和汇点只进入影响；
6. **值/不变量证据**：仅在解析与重算覆盖充分时报告，不能用平滑度直接判错；
7. **支持证据**：候选修复只记录同伴来源和可复现性，不参与基础风险。

每个提取器必须对所有公式输出原始值、等价类、支持范围和完整确定排名，并通过：

- 工作表改名、整体平移和无关格式变化不应改变结构判断；
- 合法多制度和孤立汇总不能被强行压成单一正确假设；
- 同一来源的重复邻格不能被计作多个独立证据；
- 预测分片在任何标签读取前原子写完；
- 标签置乱后，选择器性能应回到无信息范围；
- 原表/错误表只在评分阶段做成对差异分析。

信息上限报告必须区分：

- `union coverage`：多个 Top-5 列表的并集，必须同时报告最多 `5 x 通道数` 的成本；
- `oracle selector@5`：标签后为每组挑一个通道的不可部署上限；
- `fixed mixture@5`：固定席位或 RRF 产生的可部署五格参照；
- `learned selector@5`：只在外层训练组学习、测试组固定的诊断选择器。

不得再把多通道并集命中率写成一个五格模型的 Top-5 上限。

**Gate 2：以下全部满足才允许选择模型方向：**

1. `oracle selector@5` 的结构组宏 Top-5 相对 V4 至少 `+10` 个百分点；
2. Enron 与至少一个人工注入队列各有至少 `+5` 个百分点的选择余量；
3. 至少两个非同源证据族各自独有救回不少于 3 个结构组；
4. Enron 至少救回 3 个事件且来自至少 2 个工作簿；
5. 至少一半被救回源格的无标签等价类大小不超过 5，地址排序不计作救回；
6. 深度不超过 2 的诊断选择器在分组外层测试中回收至少一半 oracle 余量，且任一
   队列相对 V4 不下降超过 5 个百分点；
7. 训练折确定的选择性行动达到 acted-error precision 至少 `75%`、错误源行动覆盖
   至少 `30%`、控制行动率不超过 `15%`；
8. 分片、标签隔离、分组、置乱和指标复算全部通过。

Gate 2 失败后不得增加通道、扩大 Top-k、搜索连续权重或读取任一 `240+120` 包。

### Stage 3：按证据选择分支

Gate 2 判定后只允许进入一个分支：通过时在 A/B 中选择，失败时只进入 C。

#### 分支 A：完整的无真值继任候选

只有多类信号在 Enron 和人工注入队列都提供迁移余量时采用。候选必须输出完整排名、
支持状态、风险、影响、行动与拒绝原因，并且不调用 V4 取得最终基础排序。只有该分支
具有未来命名为 `V5-R1` 和替代 V4 主模型的资格。

#### 分支 B：可识别子集的选择性审查器

若信号只在明确可重建的区域有效，则主动缩窄主张。主要结果改为 risk-coverage、
acted precision、源行动覆盖和人工成本；全体 Top-5 仍完整报告，但不再声称通用定位。
若该分支复用 V4 排名，它只能作为 V4 系辅助模块，必须额外比较并超过现有
`V4.2-Review-B`，无论结果多好都不能命名为 V5 或声称替代 V4 主核心。

#### 分支 C：最小附加信息任务

若无真值信号门失败，停止继任 V4。另立新问题，要求用户提供一个重要输出格、一次
通过/失败标记、历史正确版本或一条领域约束，再研究依赖切片与区分性测试。该方向
必须使用新名称、新数据和新协议，并承认与 GoalDebug、SFL、不变量和交互式调试的
直接重叠。

选择 C 是科学结论，不是项目失败后偷偷放宽输入契约。

### Stage 4：候选预注册与实现

只有分支 A 或 B 被 Gate 2 授权后才写方法规格。规格必须固定：

1. 至多 12 个已通过证据门的特征，不加入语料 ID、地址和错误类型；
2. 一个可解释的低复杂度排序/校准模型，不引入神经网络；
3. 缺陷风险与传播影响分开，影响最多在同一风险带内排序；
4. 多假设区域的集合值表示和歧义惩罚；
5. 五格预算的区域去重与假设覆盖规则；
6. `review/abstain_ambiguous/unsupported` 行动规则；
7. 完整排名并列、缺失特征、语法不支持和多源块处理；
8. 一个按固定故障顺序执行的结构修订机会；
9. 所有简单组合、原实现/忠实复现基线和关键消融；
10. 训练、校准、外层评价和随机种子；
11. 一次有界参数选择的候选值、主指标和并列规则，选择完成后不再换模型族。

模型复杂度必须由样本有效结构组数量限制，不能用 220 个事件假装有 220 个独立训练
样本。开发期间的所有选择都明确标为回顾性选择，不包装成预注册发现。

### Stage 5：揭晓开发门

主要比较：V4-R1、V4.3、固定静态锚、单通道、简单 RRF/固定席位、可运行原实现或
忠实复现、候选完整模型及全部预注册消融。

主要指标：结构组宏 Top-1/3/5、MRR、Top-5 审查成本、region hit、源块覆盖、
acted precision、错误源行动覆盖、控制行动率和 risk-coverage。事件宏均值只能作为
次要结果。区间使用结构组配对 bootstrap，并同时报告配对置换检验和净胜/负组数。

**Gate 3：**

- 结构组宏 Top-5 相对 V4 至少 `+5` 个百分点，配对区间下界大于 0；
- 配对 MRR 为正，至少四个外层折不下降；
- Enron 不丢失 V4 Top-5 总命中，并至少净增 2 个来自不同工作簿的命中；
- 任一主要队列 Top-5 不比 V4 下降超过 5 个百分点；
- acted-error precision 至少 `75%`，错误源行动覆盖至少 `30%`；
- 控制行动率不超过 `15%`，合法多制度控制单独不超过 `15%`；
- 完整模型相对简单组合和关键消融存在可复算增量；
- 不支持案例、并列和失败案例全部保留。

只允许按预注册故障顺序做一次结构修订。修订后仍失败，分支 A/B 终止，不运行旧
试用包。

### Stage 6：候选锁后的旧试用包

Gate 3 通过并提交候选锁后，旧 `240+120` 只运行一次：

1. 运行前固定归档、源码、配置、环境和输出目录哈希；
2. 运行后不允许修改模型；
3. 明确称为 `revealed-trial`，不称外部验证；
4. 使用与 Gate 3 相同的性能、安全、分组和失败门槛。

失败即终止候选，新保管人数据继续不揭晓。

### Stage 7：新保管人最终盲测

旧试用包通过后才允许：

1. 完成双归档承诺和与全部开发/试用模板的重合审计；
2. 候选锁后释放无标签 PUBLIC；
3. 24 进程生成全部完整排名并锁定；
4. 锁成功后释放 SECRET，一次评分；
5. 按 30 个未见模板组报告 240 错误和 120 控制。

正式 `V5-R1` 至少要求：Top-5 相对 V4 绝对提升 5 个百分点、结构组配对区间为正、
MRR 改善区间为正、控制行动率不超过 15%、合法例外不系统退化、全部完整性审计
通过，并且候选属于独立生成完整排名的分支 A。分支 B 即使通过盲测也只能形成
`blind-confirmed auxiliary` 结论，V4 仍是主模型。任一项失败都保留为负结果。

## 8. 两条成果链仍然分开

### 8.1 继任 V4

只由相同工作簿、相同源标签和相同指标上的配对比较支持。最终新保管人盲测是最高
证据。开发交叉验证或旧试用包都不能单独支持正式继任；复用 V4 最终基础排序的
分支 B 不进入这条主核心继任结论。

### 8.2 与公开学术方法比较

只由原实现或经论文样例验证的忠实复现、共同支持子集和兼容指标支持。检测 F1、
修复准确率和源定位 MRR 不互相替代。新保管人盲测即使通过，也不自动证明超过没有
在同一输入上运行的原工具。

论文结论按证据分级：

- `implemented`: 方法或协议已实现；
- `development evidence`: 揭晓数据上观察到；
- `revealed-trial replicated`: 冻结后试用包复现；
- `blind-confirmed`: 最终盲测通过；
- `academic-baseline superiority`: 共同支持集上的原实现/忠实复现比较通过。

不得跨级表述。
