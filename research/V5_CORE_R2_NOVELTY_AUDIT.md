# FormulaGuard V5-Core R2 公开文献创新性审计

检索日期：2026-08-28  
拟议方法：Dual-Null Causal Attribution（DNCA，双空模型因果归因）

## 1. 可辩护的结论

本次检索不能、也不会证明“世界上从未有人做过”。可辩护的表述是：

> 在本次可复核检索覆盖的电子表格错误检测、电子表格公式修复、基于变异的故障定位、模型式调试和因果干预调试文献中，尚未发现一种公开方法同时满足：无正确输出或通过/失败真值；源公式排名不依赖正确修复是否进入候选池；用公式制度和图位置匹配的观测空模型；用匹配公式上的类似编辑构造安慰剂干预空模型；反事实证据只在观测不确定集合内打破并列；证据不足时显式拒绝诊断。

因此，R2 的创新主张只能落在上述**完整问题定义和机制组合**上，不能把依赖图、公式聚类、变异候选、反事实干预或拒绝预测中的任何一个单独写成首创。

## 4. 明确不主张原创的部分

1. 用依赖图表示公式传播；
2. 用公式指纹、AST或区域规律寻找异常；
3. 生成小编辑或相邻平移修复候选；
4. 替换公式并重新计算工作簿；
5. 用变异或反事实辅助故障定位；
6. 用置信度决定是否报警。

## 5. R2预登记的创新点

1. **定位与修复解耦**：没有正确修复候选时，真实源公式仍应进入高位；候选覆盖率不再是定位上限。
2. **观测匹配空模型**：以公式制度、AST复杂度、入度、出度和后代规模相近的公式为对照，估计某公式“像传播源”的经验尾概率。
3. **安慰剂干预空模型**：真实候选的恢复强度不与同格其他候选比较，而与匹配公式上相同类别的合理编辑比较。
4. **受限反事实重排**：反事实只能改变观测上无法区分的公式之间的顺序，不能把静态证据很弱的格子直接抬入Top-5。
5. **可审计拒绝**：无显著观测候选、安慰剂不显著、候选缺失、并列或副作用过高时输出相应拒绝状态。

## 6. 证据使用纪律（接受用户修订）

已揭晓的 Enron 30事件、85例独立批次和480例锁定验证可以用于：

- 失败归因；
- 机制筛选；
- 有上限且有日志的参数调节；
- 回顾性消融和压力测试。

但使用后必须改称“回顾性开发集”，不得再用于独立性或外部泛化结论。最终确认必须来自从未揭晓的新机制留出集，并满足：

- 正确到错误的平移不变公式对跨划分不重复；
- 整类变异机制留出，而不只是换行号、模板号或随机种子；
- 部分样本故意移除正确修复候选，以独立测量定位能力；
- 预测锁定后才读取标签；
- 全部有效案例保留。
