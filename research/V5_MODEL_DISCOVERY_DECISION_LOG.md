# FormulaGuard model-discovery 研究选择日志

本文件是追加式日志。每条记录必须写明观察到的证据、可作出的决定、没有作出的
决定以及是否读取了受保护标签。历史结果不能被新条目改写。

## D0001：研究线重置

- 日期：2026-08-31
- 依据：V5-Core、R2、PSL 的失败审计；Phase 0 数据分组审计。
- 观察：合成数据上的高分与生成机制重合；Enron 的自然错误结果没有显示稳定提升；
  公开压力和历史数据的事件数高于独立结构组数。
- 决定：停止继续调旧权重，启动 `model-discovery`；`V4-R1` 继续冻结主模型。
- 没有决定：没有选择区域、图、语义、反事实或学习排序器作为新核心；没有创建
  另一个 reset 版本；没有恢复任何旧 V5 名称。
- 受保护数据：未读取旧或新 `240+120` 的内容、标签或承诺以外的字段。
- 可复核依据：`research/V5_CORE_FIRST_PRINCIPLES_DISCOVERY_PLAN.md`、
  `results/core_reset_b_phase0/data_audit.json`。

## D0002：数据角色重分类

- 日期：2026-08-31
- 依据：公开压力清单、Enron 清单、历史 100 分组和现有语料注册表。
- 观察：Enron 是当前主要自然错误来源；Info1 只有 2 个纳入事件；Modified EUSES
  和 Integer 主要是注入故障；FoRepBench 是修复任务；SpreadsheetBench 是解析压力。
- 决定：按 N1/N2/N3/U 分层报告，不再把六个公开来源称作六份可互换的定位验证。
- 没有决定：没有把任何注入故障队列写成自然错误频率证据；没有把修复或解析指标
  与源定位 MRR 混合。
- 受保护数据：仅使用已揭晓清单和 Phase 0 审计；未读取任何最终盲测标签。
- 可复核依据：`research/V5_MODEL_DISCOVERY_DATA_LEDGER.json`。

## D0003：统计功效边界

- 日期：2026-08-31
- 依据：Phase 0 精确配对符号检验设计敏感性。
- 观察：25 个 Enron 工作簿组或 30 个最终模板组对 5 个百分点 Top-5 差异的最大
  保守检出功效约为 3.58% 和 4.01%。
- 决定：在候选锁前增加独立模板，或把结果明确标为估计/探索性证据；不在揭晓后
  降低 5 个百分点门槛。
- 没有决定：没有宣称当前盲测样本足以证明确认性优势；没有使用事件数替代结构组数。
- 受保护数据：功效计算未读取模型预测或盲测标签。
- 可复核依据：`research/V5_MODEL_DISCOVERY_POWER_REPORT.json`。

## D0004：下一步授权边界

- 日期：2026-08-31
- 当前状态：Gate 0 任务/功效冻结完成后进入 Gate 1；Gate 1 只完成文献卡和官方
  ExceLint 可运行性检查。
- 授权：可创建方法卡、基线适配器和无标签原子信号审计；可运行短测试。
- 未授权：新继任模型代码、连续权重搜索、扩大 Top-k、读取旧试用或新保管人数据。
- 下一条决策：只有 Gate 2A/2B 的固定外层测试结果出来后，才能在 A/B/C 中选一个分支。

## D0005：执行计划 v3 与核心假设重置

- 日期：2026-08-31
- 依据：Gate 0/1 回执、V5-Core/R2/PSL 失败审计和选择性基线诊断。
- 观察：旧研究线反复把结构异常、传播影响和修复响应合成单一排名分数；在单工作簿
  无真值条件下，合法多制度和信息不足案例不可由更多组件补出作者意图。
- 决定：当前主问题改为“多视角无标签证据能否安全支持选择性复核”；完整排名只有在
  固定 Gate 2 通过后才作为分支 A；否则转入 V4 系辅助或最小附加信息。
- 允许工作：无标签原子信号分片、确定性输出、独立评分器和短测试。
- 禁止工作：连续权重搜索、合并前人组件作为原创主张、读取两套 240+120、实现继任
  模型或用标签反向改写排名。
- 受保护数据：本决定未读取旧试用包或新保管人包。
- 可复核依据：`research/FORMULAGUARD_MODEL_DISCOVERY_PLAN_V3.md`、
  `research/V5_MODEL_DISCOVERY_GATE1_RESULT.json`、
  `research/V5_SUCCESSOR_BASELINE_DIAGNOSTIC_RESULT.md`。

## D0006：Gate 2 分支判定

- 日期：2026-08-31
- 依据：`results/model_discovery_gate2_final_v3/gate2_receipt.json`；196 个观测工作簿
  的无标签信号和 V4 基线均完整后才读取 220 个揭晓开发事件。
- 观察：固定 selector 的结构组宏 Top-5 在 Enron 为 38.67%（V4 为 52.00%），在
  Integer corpus 为 46.30%（V4 为 41.67%），在 Modified EUSES 为 71.67%（V4 为
  82.50%），在历史 100 为 84.74%（V4 为 62.11%）。选择性行动精度 62.93%、错误源
  行动覆盖 38.42%、控制行动率 36.67%。
- 决定：Gate 2A 和 2B 均不通过，选择分支 C；停止同一批标签上的连续权重、通道、
  Top-k 和规则搜索，进入四种最小附加信息的独立测量。
- 没有决定：没有创建 `V5-R1`，没有把 oracle selector 当成模型，没有把不同输入的
  旧 V4.2 输出伪造成同输入比较，也没有读取任何保管人 SECRET 数据。
- 论文边界：在 RQ-C 完成前只保留 `V4-R1` 为主模型；若 RQ-C 也不能形成安全增量，
  主结论应写为无标签可识别性边界与最小信息需求。

## D0007：RQ-C 最小附加信息结果

- 日期：2026-08-31
- 依据：`results/model_discovery_branch_c/branch_c_receipt.json` 和
  `research/V5_MODEL_DISCOVERY_BRANCH_C_RESULT.md`。
- 观察：一个输出格的依赖锥在 220 个事件上错误行动精度为 29.47%，控制行动率为
  100%；加入一个通过/失败位把控制行动率降为 0%，但错误源覆盖仍为 29.47%。在有
  核验历史版本的 90 个公开压力事件上，公式差异和单格精确约束均达到 100% 事件命中，
  这属于输入本身携带差异的上限。
- 决定：RQ-C 完成；不创建无标签继任模型，不把交互式上限改名为 `V5-R1`。论文主线
  保留 `V4-R1`，新增“无输出真值可识别性边界与最小信息需求”结果。
- 没有决定：没有读取保管人目录，没有把历史版本/约束上限与无标签成绩合并，没有在
  Gate 2 标签上继续搜规则或调参。

## D0008：跨工作簿角色先验的独立可行性门

- 日期：2026-08-31
- 依据：Gate 2 A/B 失败、RQ-C 完成；SheetJS Enron 公开仓库远程树元数据和
  `research/V5_CROSS_WORKBOOK_ROLE_PRIOR_PLAN.md`。
- 观察：Gate 2 只使用单工作簿内部证据；仓库中尚未检验过来自独立无标签真实工作簿
  的角色分布能否为单表内无同伴公式提供信息。SheetJS `enron_xls` 固定提交的
  `nuix/` 子集提供了一个规模受控、CC0 的候选无标签语料。
- 决定：在读取 SheetJS 工作簿内容前冻结 `CWRP` 自监督协议、模板去重、五折外层
  拆分、三项可用性/信息/校准门和失败停止规则。它是新的输入信息可行性实验，不恢复
  Gate 2 通道搜索，也不授权 `V5-R1` 名称。
- 没有决定：没有认定跨工作簿学习有效，没有实现定位候选，没有降低旧 Gate 2 门槛，
  没有把公式恢复任务当成错误定位结果。
- 受保护数据：未访问两套 `240+120`；未读取其路径、文件名、内容或标签。预注册前仅
  校验公开仓库 HEAD、远程树范围和许可证元数据，尚未物化 `nuix/` 工作簿内容。

## D0009：CWRP 解析覆盖阈值澄清

- 日期：2026-08-31
- 依据：实现转换清单时发现 D0008 预注册只写了“公式不可解析比例过高”，未给数值。
- 决定：在下载或打开任何 SheetJS 工作簿之前，将单工作簿进入语料的最低可解析公式
  比例固定为 50%，并要求至少有一个公式。该阈值不得依据 U0 结果修改。
- 没有决定：没有观察转换成功率、公式数量、公式语法或任何自监督成绩。
- 受保护数据：未访问；SheetJS 工作簿内容也尚未物化。

## D0010：DRFV 语料门失败

- 日期：2026-08-31

## D0011：公开上下文模型审计与 FCRL 选择

- 日期：2026-08-31
- 依据：HERMES 提交 `e8a9f6c`、TUTA/ForTaP 提交 `4de8bba`、ACL 2023 HERMES
  论文、ACL 2022 ForTaP 论文及 SheetJS 固定树元数据。
- 观察：HERMES 公共仓库只有 README 和演示视频；ForTaP 有 MIT 代码与基础检查点，
  但预训练语料不公开且 Enron 微调权重与本项目安全集重合；EDRM 有 20,256 份原始
  工作簿但存在个人信息和 Enron 重合风险。
- 决定：预注册 FCRL。只允许冻结的 ForTaP 基础权重、SpreadsheetBench v1 input-only
  训练和新的反事实后悔值定位头；禁止 Enron 微调权重，暂不下载 EDRM 内容。
- 没有决定：没有声称 HERMES 可复现，没有把 ForTaP/Transformer/公式生成写成原创，
  没有恢复 DRFV，也没有授权正式 `V5-R1`。
- 受保护数据：公共来源审计期间发生一次路径级枚举偏差；没有读取文件、内容、标签或
  哈希。完整记录见 `research/PROTECTED_DATA_ACCESS_INCIDENT_20260831.md`。
- 可复核依据：`research/V5_FCRL_MECHANISM_SELECTION_AND_PREREGISTRATION.md` 和
  `research/V5_FCRL_PREREGISTRATION.json`。

## D0012：FCRL U0 工件与适配门通过

- 日期：2026-08-31
- 依据：`research/V5_FCRL_ADAPTER_IMPLEMENTATION_FREEZE.md`、
  `research/V5_FCRL_U0_RESULT.md` 和不可变 U0 回执。
- 观察：官方 base checkpoint 的 205/205 个骨干张量逐键/逐形状匹配；目标公式和缓存
  值改变不影响 encoder 哈希，两个独立进程哈希一致；冻结骨干 GPU 前向与官方 LSTM
  解码器反向均产生有限值。
- 兼容边界：官方 `FPTUTA` 因未声明 `torch_scatter` 不可直接导入；官方 LSTM attention
  存在 query 与 key/value 布局不一致，已在任何语料样本构造前固定为只转置 key/value。
- 决定：U0 通过，允许按预注册构建 SpreadsheetBench v1 input-only 训练样本并执行 U1。
- 没有决定：没有证明公式预测有效，没有运行定位、没有超过 V4、没有授权 `V5-R1`。
- 受保护数据：未列目录、未哈希、未读取、未用于 U0；U1-U4 和完整公开预测锁前继续
  不可访问。
